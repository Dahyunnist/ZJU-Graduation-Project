# 综述与研究方案交付说明

本目录为可直接并入毕业论文的阶段稿，内容核验日期为2026-07-16。

## 文件说明

- `main.tex`：论文式LaTeX独立文档，使用`ctexart`、`biblatex`与GB/T 7714-2015顺序编码参考文献。
- `references.bib`：本稿引用的BibTeX文献库。
- `manuscript.md`：正文单一内容源，便于审阅和后续机械生成不同格式。
- `preview.typ`：与正文同内容的Typst排版源（文件名沿用历史命名，成品不含“预览版”字样）。
- `output/pdf/国内外研究综述与研究方案.pdf`：已编译并逐页检查的22页正式PDF，可直接用于导师审阅。
- `文献持续更新记录.md`：交稿前持续检索和调整对比算法矩阵的记录模板。

## 本轮整改对应关系

- 将全部相关工作统一纳入“国内外研究综述”一章，按样本级检测、语料级比例估计、污染效用与估值三条任务线组织，并在章末综合比较国内外研究格局。
- 清除正文中的说明书、交差和章节安排等脚手架式元话语，为各级章节增加论文式总述，并扩写核心方法的机制、假设、优缺点与适用边界。
- 分任务线给出对比算法基本原理、文献来源、对比角色、适用协议、当前复现进展和下一步正式实验要求。
- 分别列出Track A与Track B的数据规模、特征类型、标签/缺失情况、冻结划分及本地准备状态，并补充生成器准备矩阵。
- 正文采用可点击的数字上标引用；LaTeX版本与预览PDF均使用GB/T 7714-2015顺序编码参考文献。

## LaTeX编译

建议在安装TeX Live 2024/2025及`gbt7714`、`biblatex`、`biber`后执行：

```text
xelatex main.tex
biber main
xelatex main.tex
xelatex main.tex
```

如学校论文模板已经定义文档类、标题页、页眉页脚和参考文献样式，请保留正文中从“引言”到“结论”的章节，将其复制到学校模板，并继续使用`references.bib`。若本机缺少`gb7714-2015`样式，可临时将`main.tex`中的`style=gb7714-2015`改为`style=numeric`；正式提交前应恢复学校要求的GB/T 7714格式。

## 科研表述边界

1. 当前19个核心运行单元达到R2（代码闭环），只证明小规模训练/拟合、推理、保存/加载、指标与汇总链路完整，不应写成“复现论文性能”或正式对比结论；R3/R4均为0项。
2. DWT与DWT+TA为论文对齐自实现，AAAI正式页面尚未提供可核验的官方仓库；正文已明确标注。
3. LLM-as-a-Discriminator、几何感知贝叶斯量化和验证诱导Shapley漂移为2026年预印本，已与正式发表工作分层。
4. 当前格式诊断AUROC为0.6861，正式实验前必须先统一真实/合成数据的缺失标记、数值精度和序列化格式。
5. 当前PDF可用于综述与研究方案阶段的导师审阅；其中run-through数值均标明证据边界，最终论文性能数字仍须由正式五种子、完整协议运行生成后替换。
