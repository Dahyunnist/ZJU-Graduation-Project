# Governance Pilot 深度检测稳定性重跑完成报告

## 1. 结论

`governance-pilot-v1` 的深度检测稳定性重跑已完成。全部 22 个分片均生成有效完成标记并成功聚合，聚合状态为 `complete`，`analysis_ready=true`。本轮共形成 25,740 条检测—污染率估计—治理决策证据和 52,000 条样本估值记录；全部九种污染率估计方法均未出现失败或非有限估计。旧 pilot 中深度模型输出常数、后续估计不可用的问题已经排除。

该结果属于单随机种子的 pilot 证据，用于验证实验链路、发现研究现象和冻结正式实验方案，不能替代多随机种子的正式结果或直接用于显著性结论。

## 4. 与中心研究问题相关的初步发现

### 4.1 生成器迁移首先损害排序与校准，并放大污染率误差

从 P1 到 P2，三种深度检测结构的测试 AUROC 均下降，ECE 均显著上升。与此同时，平均污染率 MAE 从 P1 的 0.0294--0.0464 上升到 P2 的 0.1095--0.1237。这为“检测误差向污染率误差传导”提供了跨结构一致的 pilot 证据。

### 4.2 跨表情形下，AUROC 不能单独代表治理可用性

P3/P4 中部分模型仍获得约 0.75--0.78 的 AUROC，但测试 FPR 接近 1、ECE 超过 0.42，污染率 MAE 约为 0.66。由此可见，模型可能仍保留一定样本排序能力，却因分数尺度和阈值无法跨表迁移而对几乎所有真实记录报阳性。若只报告 AUROC，会掩盖其在污染率估计和治理决策层面的失效。

### 4.3 表适配恢复部分排序能力，但不足以恢复污染率估计

在 P3 中，Datum-wise + TA 相比 Datum-wise 骨干将测试 AUROC 从 0.4564 提升到 0.7538，并将 FPR 从 1.0000 降至 0.9240；然而平均污染率 MAE 仅从 0.6668 降至 0.6560，仍处于不可用水平。初步结果表明，域不变表示学习与跨域概率校准、阈值迁移是两个不同问题；后续算法定位应从“提高检测 AUROC”进一步收紧为“在模式变化下保持可校准的检测分数，并控制误差向污染率和治理决策传导”。

## 5. 后续准入要求

正式实验仍需至少五个随机种子和配置规定的 100 个污染袋，并报告置信区间和配对检验。进入正式实验前应先围绕 pilot 暴露的核心故障增加跨表校准/阈值迁移基线和误差分解：区分排序误差、校准误差、FPR/TPR 迁移误差及量化器误差，并测量这些误差对治理阈值决策和下游效用损失的独立贡献。
