# E1C：Credit 类内结构扰动与学习器响应

日期：2026-10-07。性质：E1 结果引导的探索性机制诊断；同一固定合成池、三个重复划分，不能视作独立生成器训练或外部验证。

## 核心问题与实验完整性

E1 发现 Credit/CTGAN 的类内逐列重排损害 LR，却小幅改善 RF。E1C 在相同合成行、相同替换位置、相同真实测试下复现该现象，并新增对**独立真实替换行做同样类内重排**的负对照。另以 TVAE 作生成器对照。模型为原始 LR 和 RF（叶节点 3）；用训练/测试之外的 500 行真实校准集作固定单调下游概率校准。共 6/6 分片、48 次拟合、96 行指标；所有源池与划分 ID、模型、校准器及逐样本预测可追溯。

独立审计核验：四种真实数据用途互不重叠；每个分片的四条件×两模型×两概率模式完整；类内逐列重排严格保持各标签内各列的经验边际及标签计数；全部预测与记录的 log loss 一致。自然与合成重排的原始结果共 24 项 log loss 与 E1 对应记录逐项完全相同。

以下差值均为“重排减原样”；log loss 和 Brier 越低越好，AUROC 越高越好。数值为三个种子的描述性均值，不作显著性宣称。

| 生成器、模型 | 合成重排 Δlog loss：原始 / 校准 | 合成重排 ΔBrier：原始 | 合成重排 ΔAUROC | 真实重排 Δlog loss：原始 / 校准 | 主要边界 |
|---|---:|---:|---:|---:|---|
| CTGAN、LR | +0.02754 / +0.00098 | +0.00512 | −0.00331 | +0.01637 / −0.00238 | 原始概率损害在真实对照也出现，校准后近零 |
| CTGAN、RF | −0.00376 / −0.00583 | −0.00113 | +0.00807 | +0.00295 / +0.00023 | 合成重排三种子均改善多个指标；真实重排方向不稳 |
| TVAE、LR | +0.03235 / −0.00169 | +0.00365 | −0.00067 | +0.01637 / −0.00238 | 原始损害部分是学习器/概率行为而非生成器特有 |
| TVAE、RF | +0.00874 / +0.00317 | +0.00241 | +0.00080 | +0.00295 / +0.00023 | 未复现 CTGAN/RF 的改善 |

CTGAN/RF 的合成重排在三个种子上，原始 Δlog loss 为 −0.00434、−0.00350、−0.00345；校准后为 −0.00812、−0.00451、−0.00488；AUROC 均增加约 0.0074–0.0087。这表明它不只是 E1B 所见“未校准 log loss 端点幻象”。但是对**真实行**重排时，RF 原始 Δlog loss 为 +0.01095、−0.00528、+0.00319，方向不一致；合成效应减真实效应的差中差也不是三个种子同向。因此目前只可说 CTGAN 合成池出现一个稳定的小幅模型响应，不能说“类内依赖破坏在合成数据上必定有益”或“已证明特定伪相关的因果路径”。

此外，CTGAN/RF 即使合成重排，原始平均 log loss 为 0.4543，仍不如独立真实行替换的 0.4480；“相对自然 CTGAN 改善”不等于“合成数据优于真实数据”。

结构侧的局部读数是：Credit/CTGAN 自然合成行的数值类内相关误差均值约 0.1199，重排后约 0.2267；TVAE 是 0.1478→0.2279；真实行是 0.0777→0.2292。类内单列边际则严格不变。这说明跨列关系被实际扰动，**但数值相关误差并不等于所有任务相关联合结构**；RF 的小幅改善不能解释为“结构越差越好”。

## 研究决策

1. 将“校准后 CTGAN/RF 对类内结构扰动仍有小幅响应”保留为候选机制；将“LR 原始 log loss 损害”降级为高度依赖概率口径的现象。
2. 下一次只在 Credit/CTGAN 上做预先定义的局部结构干预：逐列重排强度 0/25/50/100%，以及少量基于训练域知识确定的特征块；同时保留真实行同类干预和 TVAE 对照，分析 RF 预测变化、正/负类与预定义组别风险。先检查效应是否随实际结构变化呈合理剂量趋势；没有趋势就停止扩展。
3. 新近的跨列依赖工作已经使用控制置换和交互敏感检测。本课题的潜在独特性必须落在**结构失真如何通过模型响应影响来源治理的最终任务决策**，并最终在新生成池、新表和不同预处理下确认。目前尚未跑治理动作实验，不能宣称已有完整链条的 finding。
