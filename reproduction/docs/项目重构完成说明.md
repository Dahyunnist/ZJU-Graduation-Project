## 3. 本地smoke验证范围

本地smoke使用三个不同schema的确定性表和三种合成机制，覆盖P1--P4、0%/5%/10%/25%/50%污染率。它验证：

- 记录分区冻结且无泄漏；
- 检测得分只校准一次并被所有量化器复用；
- 污染bag成员比例精确；
- 同一证据行包含检测、比例、效用和决策字段；
- 伪影门禁能够保留并标记风险，而不是删除不利结果；
- smoke结果被标为 `formal_inclusion=false`。

smoke数值仅用于工程和逻辑核验，不能作为论文结论。

## 4. 正式运行前仍需完成

项目代码已经具备服务器执行入口，但正式实验不会在缺少数据时假装启动。当前明确阻塞项为：

2. 生成Adult、Credit及B-small训练表的独立训练/校准/测试合成池；
3. 完成 `data/governance/pool_registry.csv`；
4. 核对DWT/DWTA与论文正式超参数及训练预算；
5. 根据GPU时间先运行单seed pilot，再启动五seed正式矩阵；
6. 增加置信区间与配对统计检验汇总；
7. 如完成可靠复现，再加入Continuous Sweep等新增量化方法。

正式配置的preflight在注册表缺失时返回 `passed=false` 和明确原因，不会训练模型。
