# 统一治理基准实验契约

## 1. 冻结原则

正式实验开始前冻结以下对象：数据版本、生成器源训练区、评测真实记录区、生成器版本与种子、合成池、P1--P4协议、污染率、bag成员、检测器校准集、下游纯真实测试集、指标和统计方法。测试结果不得反向改变这些定义。生成器源训练区与评测真实记录区按目标标签分层划分且记录互斥；生成器只能拟合前者，检测、比例估计和下游效用只能从后者继续划分真实记录，避免生成器间接见到最终测试样本。

## 2. 数据注册表

正式数据由 `pool_registry.csv` 注册，每行对应一个“表×生成器”的合成池，并包含：

| 字段 | 含义 |
|---|---|
| `table_id` | 稳定表标识 |
| `domain` | 数据领域，只用于协议和分层统计 |
| `target_column` | 下游任务标签列 |
| `generator` | 合成器名称与版本对应的逻辑标识 |
| `real_path` | 清洗后真实表路径 |
| `synthetic_path` | 与真实表同schema的独立合成池路径 |
| `quality_score` | 由冻结真实评测区与合成池计算的SDMetrics总体质量分数 |

记录来源、表名、生成器、分区和ID属于provenance字段，不得进入检测器特征。正式注册表不得使用本机绝对路径。

## 3. 协议约束

- P1要求训练和测试使用相同表集合、相同生成器集合，但记录ID必须不重叠。
- P2要求表集合相同、生成器集合不相交。
- P3要求表集合不相交；生成器可以相同，以隔离schema迁移。
- P4要求表集合和生成器集合均不相交。
- 固定schema C2ST不得参加P3/P4；跨表方法必须使用表无关表示。

每次运行保存 `protocol_manifests.json`。协议验证失败时禁止训练。

## 4. 检测层

检测训练集保持真实/合成平衡，以比较来源识别能力；最终污染bags使用真实目标污染率。检测层至少输出AUROC、AUPRC、Brier、ECE、FPR、TPR、Precision和Recall。

检测阈值只根据训练表的冻结验证集选择，并满足预设FPR约束。测试表不得参与阈值选择或概率校准。

## 5. 格式伪影门禁

伪影诊断器只能使用与语义无关的格式统计，包括缺失数、空字符串数、序列化长度、字段最大长度、数值字段比例、整数比例和小数位数。为捕捉跨域方向翻转，门禁使用 `max(AUC, 1-AUC)`。

若伪影AUROC不低于0.65：

1. 不删除该实验；
2. 将 `artifact_gate_passed` 标为false；
3. 检测结果必须附伪影警告；
4. 后续加入规范化/格式匹配消融，检验性能是否仍存在。

## 6. 比例估计层

所有量化器共享冻结的校准得分和bag得分。核心方法包括CC、PCC、ACC、PACC、EMQ、HDy、DyS、Median Sweep和连续密度KDEy。正式实验可继续加入Continuous Sweep，但新增方法不得改变既有bag成员。

每个方法报告：原始估计、截断估计、MAE、Bias、MSE和失败诊断。5%与10%单独汇总，并报告理论假阳性质量及其在观测阳性中的占比。

污染构造同时覆盖两种机制：`replace`在固定总预算内用合成记录替换真实记录；`append`固定真实训练基底并额外加入合成记录。两者必须分组报告，不能把“新增数据的潜在增益”和“固定预算下的替换损失”混为同一因果解释。

## 7. 下游决策层

下游效用评估采用与污染bag同表、但记录隔离的纯真实测试集。每个纳入效用评估的bag计算：

1. `U_clean`：等预算纯真实训练；
2. `U_keep`：保留污染bag；
3. `U_detector_clean`：按冻结检测阈值删除疑似合成记录；
4. `U_oracle_clean`：按真实来源删除合成记录，仅作为诊断上界。

量化器估计超过治理阈值时触发清理。决策遗憾定义为当前可用动作中最优效用与实际策略效用之差。`U_oracle_clean-U_detector_clean`用于度量样本检测误差在清理环节造成的额外损失。

除总体效用外，正式矩阵还使用KNN-Shapley和Data-OOB计算逐记录任务价值，保留真实/合成来源标签及Data-OOB覆盖次数，用于检验来源身份与任务价值是否解耦。数据价值是第三层的诊断解释，不另起一条与中心问题脱节的实验线。

比例估计需要大量bags，而效用训练成本更高；因此正式配置可令 `utility_bags_per_rate < bags_per_rate`。未进入效用子样本的行保留比例估计证据，但决策字段记为空，不得误记为零损失。

## 8. 统计汇总

正式主结果使用5个冻结种子。连续指标报告均值、标准差和95%置信区间；模型配对比较必须在相同seed、table、generator、污染机制、rate和bag上完成，并对多重比较采用Holm校正。除总体宏平均外，必须保留最差表结果以及5%/10%分层结果。

## 9. 结果有效性标签

- `smoke`：验证接口和数据契约，不进入论文正式统计。
- `pilot`：验证资源、时间和超参数量级，不进入正式统计。
- `formal`：仅在预注册矩阵、完整制品和成功门禁下纳入论文结果。

任何失败、阻塞和伪影门禁失败都应保留记录，不得静默覆盖或从汇总中无解释删除。
