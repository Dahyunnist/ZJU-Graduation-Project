# 下一阶段聚焦探索计划

日期：2026-10-02。性质：研究设计，尚未执行。先修复证据口径，再进行小规模机制探索；不立即重跑历史全矩阵。

## 1. 一个中心问题，两个层次的成果

中心问题：**当训练集混入合成数据时，哪些任务相关失真决定模型风险，来源检测驱动的治理在什么条件下缓解或放大这些风险？**

study 是核心：找出可复查、能解释条件边界的机制。benchmark 是载体：将必要的场景、接口和指标组织成别人可接入的评测工具。二者共用实验，不分别开两套庞大工程。

不预先假定合成数据有害，不预先假定校准一定能改善下游，也不将“合成来源”作为“应删除”的真值。最终允许得到有条件的正结果、负结果或等效性证据。

## 2. 统一逻辑与变量

```text
生成条件 G（训练量、生成器、独立种子）
    ↓
合成数据结构 Z（标签比例、类内结构、尾部覆盖、重复）
    ↓                         来源检测 D
混合训练集 B                  ↓
    │                    校准 C / 阈值 T
    │                         ↓
    │                    比例估计 Q
    │                         ↓
    └──────────────→ 治理动作 A（保留、删除、弃权）
                              ↓
                    保留集合 R（数量、类别、尾部组成）
                              ↓
                    学习器 M → 真实测试风险 L
```

这里的箭头是待检验机制图，不是已经从观察数据识别的因果图。检测分数、来源概率、任务预测概率必须分字段命名，避免把来源校准和下游预测校准混淆。

定义两个主要比较量：

- 数据效应：同预算、同划分下，混合数据训练风险减去真实参照训练风险。
- 治理效应：同一个 bag 下，执行策略后的风险减去不清理风险；负值表示风险降低。

第二个量必须使用同 bag、同模型设置、同测试集。来源删除 oracle 只提供知道来源的参考，不是任务效用上界；真正的决策 oracle 也只能称为预定义候选动作集合中的事后最优参照。

## 3. 三个可证伪问题

| 问题 | 假设/候选解释 | 支持它需要什么 | 什么结果会否定或收窄它 |
|---|---|---|---|
| RQ1：相同合成比例为何出现不同任务风险？ | 条件结构和少数/尾部覆盖比单一来源比例更能解释风险变化 | 控制样本量和比例，分别干预结构，跨模型/数据重复；留出数据集预测风险 | 结构指标无额外解释力，或效应完全由样本量解释 |
| RQ2：校准如何影响治理结果？ | 通过改变动作或删除集合，产生选择性误删；不是校准指标直接决定效用 | 冻结分数，独立干预映射、阈值和动作；记录误删群体及风险；保序负对照 | 映射变化不改变动作，或改变动作却无实质风险效应 |
| RQ3：何时来源清理不如简单基线？ | 在质量较好或稀有信息较多的合成数据中，删除有用样本的代价超过来源净化收益 | 同预算随机删除、保留、来源 oracle、受限任务策略的配对比较 | 来源清理在预算匹配后始终稳健占优，或优势完全解释为规模变化 |

RQ1 是第三层主轴，RQ2 是前两层向第三层传导的机制，RQ3 给出可操作治理边界。不是要求最后必须写出三个独立 finding。

## 4. 阶段 E0：历史证据修复与缓存盘点（先做，不训练）

输入：历史代码基点、配置、原始 evidence/valuation、数据池和已有输出登记。

1. 盘点逐样本原始分数、来源标签、任务标签、保留索引、检测 checkpoint 是否真的保存。缺失项列清单，不把汇总表当逐样本缓存。
2. 低比例条件按 nominal_prevalence 选择，误差按实际比例计算。如果旧输出字段不存在，用冻结配置和 bag 标识恢复并逐项验证，不靠模糊浮点取整猜测。
3. 对效用提取唯一基础 bag 表。keep/clean/oracle 不以量化器成功为前置条件；删除动作表保留 detector/policy 维度，策略决策表才包含 quantifier。
4. 按每个指标报告总数、有效数、失败数；非法训练集（空、单类别等）显式列为不可行动，不把它们默默排除后称为稳健。
5. 输出“旧口径→修正口径”差异及原因。原输出只读，新目录使用不同 analysis_id，并记录输入 SHA256 和代码版本。
6. 独立核验 key 去重、同 bag 一致性、append 比例和规模、π=0 对照、原始值截断、统计重复单位。

交付：修正版描述性表、可复用 bag/action 表、缓存缺口、仍稳定的候选现象。退出条件：所有关键数值有唯一来源、失败分母清晰，足以选一两个小探索。若修正后旧现象消失，报告消失，不为保留 finding 调整口径。

## 5. 阶段 E1：先解释“数据本身怎样影响模型”

### 5.1 最小筛查矩阵

首轮用 3 个互有差异的数据集（已有 Adult、Credit，加一个事先选定且通过许可/类别审计的数据集），2 类学习器（LR 与树模型），3 个独立划分/训练种子，比例先选 0、0.1、0.5。固定总训练规模的替换模式先行；追加模式作为第二批预算控制实验。新数据集以标签不平衡、特征类型及样本规模选择，不能因为结果好看而选。

先使用可控制的半合成干预，而非一上来比较所有生成器：

| 干预 | 尽量固定什么 | 改变什么 | 需要验证的检查 |
|---|---|---|---|
| 类内特征重排 | 标签比例、各特征类条件边际、样本量 | 类内多特征联合依赖 | 验证保持量确实近似/严格不变；记录联合结构破坏强度 |
| 少数/尾部欠覆盖 | 总规模及预先定义的任务 | 某类或训练集定义的稀有区域覆盖 | 类别计数、覆盖率和真实测试群体损失 |
| 标签关系退化 | 特征及总规模，二分类时可成对交换保持类别总数 | P(Y|X) 关系 | 标签比例、关系强度与学习误差 |
| 无任务信息扰动负对照 | 有效特征和标签 | 添加/变化独立的干扰特征 | 有限样本下仍可能影响学习，不能预设风险严格为零 |

这些不是“真实生成器全部失效方式”的替代品，而是帮助识别机制的受控样本。先在合成真值可知的玩具任务上验证操作，再用于真实数据的训练部分。最终结论必须在自然生成器上验证。

### 5.2 对照必须配对

同一母训练集、替换索引、测试集、模型调参规则贯穿比较。π=0 时混合组与对应真实组使用完全相同数据及训练随机性，应作为严格一致性检查。

追加试验至少比较：原真实核心；核心+合成；核心+真实有放回重采样（仅控制样本条数/训练暴露，不冒充新增独立信息）；若有独立真实储备，可另比较核心+同数独立真实。避免把训练规模增加误认为合成分布优势。

删除试验至少比较：保留；检测删除；相同删除数量的随机删除；相同类别/群体预算的匹配删除（事后诊断参照，明确使用的信息）；真实来源 oracle 删除。每个动作保留列表可审计。

## 6. 阶段 E2：解释校准—比例—决策的传导

冻结一个可信来源检测器及其原始输出，再研究校准，避免每换校准同时换检测器。先比较 source-only 和真实目标锚点阈值；另设小规模带来源标签的目标校准集，明确该条件的信息成本，不假装与“只有干净真实锚点”条件相同。oracle 仅诊断且不得使用最终任务测试集。

校准器从无校准、Platt 开始，样本规模允许时加入 isotonic/temperature 等合理参照。概率输入与 logit 输入必须区分；概率预测使用 log loss/Brier 评价，ECE 仅辅助，分箱敏感性单独报告。

量化器主分析先 CC 与 PACC，一个暴露运行点偏差，一个代表软分数校正。仅当可识别性条件成立时才解释估计精度；ACC/PACC 分母过小的拒绝输出应是规范结果。

将以下两个开关分别实验：

1. 是否触发治理：按比例阈值、始终保留、在独立验证上选择的任务风险策略。
2. 治理时删哪些行：固定 FPR 阈值、固定数量 top-k、随机同预算、来源 oracle。

关键负对照：严格递增变换分数并同步变换阈值，删除集合应不变；固定 top-k 在无并列/约定并列处理时也应不变。如果效用改变，先排查实现或随机性，不声称发现“校准隐性效应”。

记录完整中间量：原始分数→映射分数→阈值→原始/截断比例→动作→删除数→误删真实数→各类/尾部保留数→下游预测。研究中介关系时以随机/受控干预为主，不能仅用相关热图宣称因果。

## 7. 阶段 E3：自然生成器与外部验证

E1/E2 出现稳定、有意义现象后再扩到 6–10 个预先选定目标数据集；至少涵盖不同类别不平衡、特征结构和规模。先 3–4 个探索，再保留未用于选假设的数据集确认，不在看完所有结果后声称预注册。

生成器：继承 CTGAN/TVAE，再按作者实现可用性和配额选择一种扩散类（TabDDPM 或 TabSyn）作为结构不同的来源。生成器训练种子与检测/学习/抽 bag 种子分别登记；不能再次把固定生成池的五次评估称为五次独立合成实验。

学习器：线性与树模型为核心，资源允许再加一个合理的神经/基础模型。相同调参预算而不是生硬相同超参；调参只用训练/验证，所有策略统一规则。方法选择和生成器版本需在当前文献对照后冻结。

留一表外验证应有多个目标表，不再把单一 Adult→Credit 当通用证据。若跨生成器现象不稳定，报告生成器特定机制，不扩大结论。

## 8. 指标不是越多越好

| 评价对象 | 主指标/记录 | 辅助指标及解释 |
|---|---|---|
| 数据结构 | 标签比例误差、类内结构偏差、预定义尾部覆盖、重复率 | TabStruct/查询型结构诊断作为候选，不盲目合成总分 |
| 来源检测 | AUROC、目标域 FPR/TPR | 来源 Brier/log loss 与校准图；不能用来源指标代替任务风险 |
| 比例估计 | 实际比例上的有符号误差、MAE、输出覆盖率 | raw 越界率、截断率、可识别性诊断 |
| 治理动作 | 删除数、误删真实率、群体保留比例 | 触发率、弃权率、计算成本 |
| 下游模型 | 真实测试 log loss 的配对变化（先定为首要结局） | Brier、AUROC、AUPRC、固定阈值/固定 FPR 的召回；任务不平衡时重点看少数类 |
| 局部风险 | 预先定义组别/尾部的损失和样本量 | 最差组指标需同时展示不确定性，不能事后挑最差小群体 |
| 决策 | 相对 keep 的风险变化、含失败/成本的决策效用 | 候选动作集合内 regret；候选集合和缺失处理明确 |

下游 proper loss 度量整体概率预测质量，不只测“校准误差”。下游若另加模型概率校准，必须作为独立且统一的步骤，不能与来源检测校准混写。

数据估值暂为辅助：KNN-Shapley/Data-OOB 可定位候选样本；决定删样本只能用独立 value-validation，最终效应仍通过配对训练验证，不能把估值分数本身当贡献证明。

## 9. 统计与成功标准

- 同一数据集/划分/生成池/模型的策略配对。bag 是重复抽样，不能当跨数据集独立样本；统计中以数据集为主要泛化单位，种子为内部重复。
- 先展示每数据集效应与区间，再汇总；避免只用多个重复策略行加权后的大总体均值。
- 首要结局和最小有意义效应在确认性试验前由任务尺度确定，不用 p<0.05 自动定义价值；比较族预先列明，必要时 Holm 校正。
- 不显著不等于等效；若要说“无影响”，预设等效界限并给出足够精度的区间。
- 探索找规律，留出验证检验规律，不能用同一套结果既选指标又证明泛化。

study 值得成文的最低证据：一个集中机制、预算匹配的干预对照、多个数据与至少两类模型的边界、能复现的反例/失败条件。不是要求所有假设都成立。

## 10. benchmark 发布门槛

| 必备要素 | 验收方式 |
|---|---|
| 明确任务与用户 | 说明输入混合数据、可用来源信息、输出治理动作；与一般生成质量基准有明确差异 |
| 代表性场景卡 | 每场景有真实来源、许可、标签、分割单位、混合预算、失真类型和适用范围 |
| 插件契约 | 新检测器/策略通过公开最小示例接入，不必修改主评测循环 |
| 预测与动作缓存 | 无需重训即可重算评价；样本 ID、模型/数据 hash、版本齐全 |
| 失败规范 | 超时、资源失败、不可识别、非法训练集、弃权明确编码，不能从总分中静默消失 |
| 公平运行 | 统一信息边界/预算/调参规则，oracle 与可部署方法分榜或分表 |
| 可信评分 | 指标单位、方向、统计单位及对照清晰；单元测试和小端到端参考结果 |
| 外部重现 | 干净 CPU 环境跑最小示例，独立使用者按文档接入一个新方法并复得表格 |
| 可维护版本 | 评分改变有迁移说明，旧 run 可重评分，冻结结果不覆盖 |

网页排行榜和大模型数量不是上述门槛的替代。若这些要素无法在可用时间内完成，则发布带评测脚本的 study artifact，也可构成合格研究成果。

## 11. 执行顺序与资源边界

第一批只做 E0；第二批完成 E1 小矩阵及 E2 一种检测器的缓存实验。资源探针记录每单元墙钟、内存、显存，再决定扩展，不现在承诺“大矩阵几天跑完”。

服务器仅用分配账号及已确认 GPU/CPU 配额，默认单任务小并发，不按“发现空闲显卡”自动抢占，不修改共享 CUDA/驱动，不停止他人进程。超过已确认预算的批次先给出估计供批准。

阶段门：E0 未通过，不重新解释旧结论；E1/E2 无稳定机制，不急着扩展数据；新颖性与相邻工作区分不清，不包装为新 benchmark；如果有效差异主要是数据集特例，收窄 study 结论而不是堆统计显著项。
