# 研究定位与实验主线

## 1. 精准定位

项目定位为 **Synthetic Tabular Data Contamination Benchmark / Audit Framework**，即“面向合成表格数据污染的数据治理评测框架”。研究对象是在来源标记缺失时混入真实语料的合成表格记录，研究目标不是单独训练一个来源检测器，而是回答以下连续问题：

1. 在未知记录、未知生成器和未知表结构条件下，合成记录能否被可靠识别？
2. 样本级检测得分能否转化为整批数据的污染率估计，尤其是在5%和10%的低污染率条件下？
3. 检测和计量误差会不会诱发错误的治理决策，并改变下游任务效用和训练样本价值？

统一科学问题表述为：

> 检测误差如何传导为污染率误差，并进一步影响下游任务决策？

## 2. 三层连续决策链

### 2.1 污染感知层

输入为单条来源未知的表格记录，输出为合成来源得分。该层同时评价排序性能、概率校准和具体运行点，避免只报告AUROC。P1用于估计同表上限，P2--P4依次引入生成器、表结构以及二者同时迁移。

### 2.2 污染计量层

输入为一个污染bag内的冻结检测得分，输出为合成记录比例。量化器共享同一个检测器、校准集和测试bag，使方法差异不会被数据变化混淆。主指标为MAE和Bias，5%与10%污染率单独汇报。

对于真实污染率 \(\pi\)、检测器真阳性率 \(TPR\) 和假阳性率 \(FPR\)，直接计数器的期望阳性率为：

\[
q = \pi TPR + (1-\pi)FPR.
\]

低污染率时，\((1-\pi)FPR\) 可能超过 \(\pi TPR\)，因此高AUROC并不保证污染率可准确估计。

### 2.3 污染决策层

每个污染bag同时构造四种下游证据：纯真实训练、保留污染、按检测器清理以及按真实来源清理。所有模型在冻结的纯真实测试集上评价。量化器输出触发“保留/清理”决策，并计算：

- 决策错误率；
- 决策后任务效用；
- 相对可用最优动作的决策遗憾；
- 检测器清理与来源oracle清理之间的效用差距。

这使“比例估计误差”不再停留在数值层面，而能够追踪到具体的治理代价。

## 3. 基准的五项特征

1. **从检测升级为污染治理。** 同一基准连接来源识别、污染计量和任务决策。
2. **强调低污染率。** 5%和10%作为独立结果层，报告FPR主导程度与校准误差。
3. **格式伪影门禁。** 仅使用缺失数量、空字符串、序列化长度、数值精度等变量训练诊断器；若其对称AUROC达到门限，正式结果必须标注风险。
4. **区分可检测性与有害性。** 结果进入“高/低可检测 × 高/低任务损害”四象限，而不预设合成记录必然有害。
5. **面向结构化模型生态。** 将合成记录视为训练、共享和增强过程中的基础材料，审计其provenance、prevalence与utility risk。

## 4. Finding导向的实验组织

所有正式结果按以下问题组织，而不是简单堆叠“算法×数据集”排行榜：

1. 同表高分是否在P2--P4显著下降？
2. 格式伪影能够解释多少检测能力？
3. 高AUROC为何不能保证5%/10%污染率估计准确？
4. 类条件得分分布漂移如何破坏量化器假设？
5. 替换/追加污染的效用是否非单调，低比例合成数据是否可能有益？
6. 来源可检测性与任务有害性是否脱钩？

代码为每个问题生成独立的 `finding_*.csv`，同时保留可回溯到原始bag的统一 `governance_evidence.csv`。

## 5. 贡献边界

项目的目标贡献是问题定义、统一基准和经验发现，而不是声称所有检测器或量化器均为新算法。DWT/DWTA、字符3-gram、C2ST、EMQ、HDy、DyS、KNN-Shapley等作为经典或最新对比方法；创新性主要来自冻结协议、低污染率、伪影审计和端到端决策传导分析。
