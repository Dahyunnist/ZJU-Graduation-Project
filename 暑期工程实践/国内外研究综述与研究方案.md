# 合成表格数据污染检测：国内外研究综述与研究方案

## 1. 研究背景与研究意义

1. 表格数据是医疗、金融、人口统计、政务和企业业务系统中最常见的数据形态。与图像、自然语言文本相比，表格数据具有显著的异构性：同一张表中通常同时包含连续数值列、离散类别列、布尔列、时间列和缺失值；列与列之间可能存在稀疏而复杂的统计依赖；连续列往往呈现非高斯、多峰、偏态和长尾分布；离散列亦可能出现严重类别不平衡。上述特征使得表格数据的生成与检测均较表面看来更为复杂。

2. 合成表格数据的应用价值较为明确：在真实数据不便直接共享的场景中，可提供开发与测试用的替代样本；在类别不平衡、隐私保护或系统压测等需求下，亦可作为数据增强手段。然而，一旦合成记录进入本应由真实样本构成的数据集，使用者可能在缺乏来源标注的情况下以混合数据训练或评估模型，进而引发分布偏移、变量关系失真、少数类别被稀释及下游性能波动等问题。

3. 本课题关注以下问题：当表格数据集中可能混入合成记录时，能否识别哪些记录为合成数据、估计污染比例，并量化该污染对下游效用与数据估值的影响？该问题具有三方面意义。
   - 其一，属于表格数据质量治理中的新议题。传统数据质量研究多围绕缺失、错误、重复和异常值展开；合成污染则涉及“来源真实性”，现有表格清洗工具对此覆盖有限。
   - 其二，将模型坍缩风险具体化到表格场景。Shumailov 等关于模型坍缩的研究表明，若反复以生成数据训练模型，真实分布尾部可能逐步消失 <sup>[12](#ref-12)</sup>。表格数据中少数类别、极端值和稀有组合在医疗、金融等任务中往往具有关键作用，合成污染对上述结构的影响需单独加以考察。
   - 其三，与数据估值及数据定价问题直接相关。训练集中若掺入一定比例的合成记录，其训练价值、分析价值及市场价值是否下降、下降幅度如何，均为数据要素流通与数据治理中的实际问题。

## 2. 国内外研究综述

### 2.1 合成表格数据生成研究
合成表格数据生成构成本课题“被检测对象”的主要来源。相关研究大致可分为统计建模、深度生成、扩散模型和大语言模型四条路线。

#### 2.1.1 统计建模、Copula 与隐私保护型方法
早期合成表格数据研究多源于统计披露控制与隐私保护数据发布。传统方法通常先估计边际分布、条件分布或变量间相关结构，再从估计分布中采样。Synthetic Data Vault（SDV）项目较早提出面向关系数据库的合成数据建模框架，其工程生态后续集成了 GaussianCopula、CTGAN、TVAE 等生成器 <sup>[[1](#ref-1), [19](#ref-19)]</sup>。DataSynthesizer 将字段类型推断、分布摘要、差分隐私噪声注入和合成数据检查组织为端到端流程，表明合成数据生成不仅限于采样，还涉及隐私与效用的权衡 <sup>[2](#ref-2)</sup>。

在隐私保护生成方面，PrivBayes 采用差分隐私 Bayesian network 发布合成数据，PATE-GAN 将 PATE 框架引入 GAN 判别器训练，以限制单个训练样本对生成模型的影响 <sup>[[3](#ref-3), [4](#ref-4)]</sup>。这类方法强调形式化隐私保证，但往往需以部分分布保真为代价。对本课题而言，统计/Copula/Bayesian network 路线及差分隐私生成器适合作为污染基准中的“统计型污染源”：可解释、可控、易复现，但在高维关联结构上也可能留下较明显的检测痕迹。

#### 2.1.2 GAN 与 VAE 路线
深度生成模型显著提升了合成表格数据的质量上限。Xu 等提出的 CTGAN 是该方向的代表性工作，针对混合类型、连续列多峰分布和离散列类别不平衡，引入 mode-specific normalization、conditional generator 和 training-by-sampling，使 GAN 能更有效地学习真实表格数据分布 <sup>[5](#ref-5)</sup>。

TVAE 代表 VAE 路线。公开可核验资料显示，TVAE 作为表格 VAE 模型在 Xu 等 NeurIPS 2019 工作中与 CTGAN 一并给出；该模型在编码器-解码器框架下，通过表格预处理、混合类型输出分布建模和 ELBO 目标优化，生成同时包含连续列和离散列的表格记录 <sup>[5](#ref-5)</sup>。

CTGAN 和 TVAE 对本课题具有直接意义：二者是构造污染基准时的主要合成来源，分别对应 GAN 与 VAE 两种机制，可能留下不同的合成痕迹，因而可用于跨生成器泛化实验。

#### 2.1.3 扩散模型、图结构模型与 Transformer/LLM 路线

近年来，扩散模型和语言模型也被引入表格生成。TabDDPM 将去噪扩散概率模型适配到表格数据，对连续和离散变量分别建模 <sup>[6](#ref-6)</sup>；GReaT 和 REaLTabFormer 等方法则将表格序列化为文本或 token 序列，再借助预训练语言模型或 Transformer 生成记录 <sup>[[7](#ref-7), [8](#ref-8)]</sup>。

上述进展表明，合成表格数据的来源已从 CTGAN/TVAE 扩展至更强的扩散模型和 LLM；近年综述也将多类型表格生成模型、效用评估和隐私风险作为核心议题 <sup>[9](#ref-9)</sup>。检测任务因此不应仅针对单一生成器。本课题优先完成 CTGAN、TVAE、GaussianCopula 和轻量 LLM 生成设置；扩散模型可在时间允许时纳入泛化测试。

### 2.2 合成数据质量、效用与隐私评估研究

合成数据评估研究主要回答三类问题：合成数据与真实数据的相似程度、对下游任务的支撑能力，以及隐私泄露风险。常见评价维度包括：

- **Fidelity**：合成数据是否保留真实数据的边际分布、列间相关和联合分布；
- **Utility**：合成数据能否支撑下游分析或机器学习任务，例如 TSTR（Train on Synthetic, Test on Real）；
- **Privacy**：合成数据是否泄露训练集中个体信息，例如 membership inference、attribute inference 和 Distance to Closest Record；
- **Alignment**：合成数据是否满足领域规则、逻辑约束和常识约束。

SDMetrics 提供 Column Shapes、Column Pair Trends、Contingency Similarity、KSComplement 等指标，用于比较真实数据与合成数据的统计相似性 <sup>[18](#ref-18)</sup>。Snoke 等进一步区分 general utility 和 specific utility，并将 propensity score mean-squared error（pMSE）系统用于合成数据评估 <sup>[10](#ref-10)</sup>。pMSE 的基本思路是合并真实和合成记录，训练分类器预测来源；若分类器难以区分，则表明两类数据更为接近。

近年的 density ratio 视角指出，real-vs-synthetic 分类器本质上可视为分布差异或密度比估计工具。该点与本课题直接相关：传统评估往往将“难以区分”视为高质量信号，而污染检测则将“可区分性”视为检测依据。二者目标不同，方法上却可相通。

因此，合成数据质量评估与合成表格污染检测虽然共享部分统计工具，但二者问题设定不同。前者通常面对已知真实集与已知合成集，关心生成结果是否高质量；后者面对来源未知或混合的表格数据，关心是否混入合成记录以及混入比例。相应地，前者主要报告 fidelity、utility、privacy、TSTR、pMSE 等指标，后者则需报告 AUROC、TPR@FPR、污染比例 MAE 和估值偏差等指标。

### 2.3 合成内容检测与数据污染研究

文本领域的机器生成内容检测已有较多研究积累。DetectGPT 基于概率曲率假设进行零样本检测 <sup>[11](#ref-11)</sup>，其他多生成器、多领域基准则关注跨模型、跨域、鲁棒性和攻击场景。这些研究表明，合成内容检测不能仅考察同一模型上的准确率，还需关注跨生成器泛化、低污染比例、校准能力以及对改写或扰动的鲁棒性。

上述方法难以直接迁移至表格数据。表格记录通常较短，缺乏自然语言中的流畅度、风格和句法线索；检测线索更多来自数值范围、类别组合、缺失模式、列间依赖和长尾结构。文本检测研究仍提供若干方法论借鉴：检测器可能过拟合某一生成器；低污染比例较之高污染更接近实际治理场景；检测分数亦可用于过滤或重加权训练数据，从而缓解模型坍缩风险 <sup>[[12](#ref-12), [13](#ref-13)]</sup>。

### 2.4 表格数据治理与 LLM 赋能检测

表格数据治理长期围绕缺失值填补、错误检测、数据修复、异常检测和公平性等问题展开。传统异常检测往往假设异常值在统计分布上稀有或偏离中心，但合成记录未必构成“异常点”：一条合成记录可能在各单列上取值合理，却在联合分布、因果关系或稀有组合上呈现细微偏差。

课题组的 TabClean 和 ZeroED 是本课题的重要背景。ZeroED 将 LLM 推理与传统机器学习相结合，由 LLM 生成错误感知特征、检测指南和少量代表样本标注，再训练分类器进行大规模检测 <sup>[14](#ref-14)</sup>。这一“LLM 负责推理和弱标注，传统模型负责规模化预测”的范式，可自然扩展至合成记录检测。

本课题与已有表格治理工作的差异在于，检测对象由“错误值或异常值”扩展为“来源为机器生成的记录”。因此，本课题既需借鉴异常检测和错误检测，同时也不能将合成污染简单等同于异常值检测。

### 2.5 模型坍缩与合成污染风险

Shumailov 等在 Nature 2024 中指出，模型若反复以生成数据训练，可能逐渐丢失真实分布尾部并发生不可逆退化 <sup>[12](#ref-12)</sup>。Gerstgrasser 等则讨论了通过累积真实与合成数据缓解递归训练风险的可能 <sup>[13](#ref-13)</sup>。这些工作共同表明：合成数据并非天然有害，但未经识别和控制的合成数据一旦进入训练管线，将改变未来模型学习到的分布。

表格数据中的长尾组合、少数群体和极端值往往具有关键意义，例如金融违约样本、医疗罕见病例或人口统计中的少数职业组合。若合成污染削弱上述结构，下游模型可能在总体指标上看似稳定，却在关键子群体上出现性能退化。因此，本课题不应仅报告检测 AUROC，还需分析污染比例变化对下游效用和数据价值的影响。

### 2.6 数据估值与数据定价相关研究

Data Shapley 将训练数据视为合作博弈中的参与者，用 Shapley value 衡量每条记录对模型性能的平均边际贡献 <sup>[15](#ref-15)</sup>。Jia 等提出 KNN-Shapley 和高效近似算法，使数据估值在近邻模型和较大数据集上更可计算 <sup>[16](#ref-16)</sup>；Data Banzhaf 则从鲁棒性角度讨论了随机训练过程下数据价值排序不稳定的问题 <sup>[17](#ref-17)</sup>。

上述研究为估值影响分析提供了工具。若合成记录的 Shapley 值系统性偏低或为负，则表明其可能损害训练集价值；若某些合成记录仍具正贡献，则表明合成数据并非一概有害，其影响取决于生成质量、污染比例和下游任务。课题组在数据定价方向已有 PerPricer 等工作，查询定价场景中亦涉及合成元组。本课题可为“合成污染如何影响数据价格”“是否需要对污染数据折价”等问题提供实证依据。本科阶段仍以实证观察为主，不追求数据估值理论的新推导。

### 2.7 国内外研究对比与研究空白

国内外已有研究为本课题提供了生成器、评估指标、检测范式、风险动机和估值工具，但空白仍然明显。统计与隐私保护合成方法（如 SDV、DataSynthesizer、PrivBayes、PATE-GAN）具有可控、可解释和易复现的特点，可作为本课题的统计型污染源与评估参照 <sup>[[1](#ref-1)–[4](#ref-4), [19](#ref-19)]</sup>；深度表格生成与 LLM 表格生成方法（如 CTGAN、TVAE、TabDDPM、GReaT、REaLTabFormer）说明合成数据源正变得更加多样，也使跨生成器检测成为必要 <sup>[5](#ref-5)–[9](#ref-9)</sup>；合成数据质量评估方法（如 SDMetrics、pMSE）可为统计基线和比例估计提供信号，但其目标通常是评价生成器，而非估计未知混合集中的污染比例 <sup>[[10](#ref-10), [18](#ref-18)]</sup>；文本生成检测、ZeroED 和数据估值研究则分别为跨模型检测、LLM 赋能检测和估值影响分析提供方法参照 <sup>[[11](#ref-11), [14](#ref-14)–[17](#ref-17)]</sup>。

综合来看，本课题面对的主要空白可以概括为三点：

1. 缺少可复现的合成表格污染检测基准，尤其是多生成器、多污染比例、防泄漏划分的实验协议；
2. 缺少统计方法、监督分类器和 LLM 赋能方法在统一接口下的公平比较；
3. 缺少合成污染对下游效用和数据估值影响的系统实证。


## 3. 研究目标与研究边界

### 3.1 研究目标

本课题拟完成以下目标：

1. 构建可复现的合成表格污染检测基准，覆盖至少两个真实数据集、至少三类生成器（CTGAN/TVAE/GaussianCopula，LLM 作为扩展）、全生成与条件生成两种合成方式，以及多个污染比例；
2. 实现并比较四类检测方法——统计分布漂移、密度/典型性检测、训练式分类器和 LLM 赋能检测，统一 `score(x)` / `predict(C)` 接口；
3. 在样本级检测和语料级污染比例估计两个任务上进行公平评测，并报告效率指标；
4. 初步分析合成污染比例对分类与回归下游效用及数据估值指标的影响；
5. 沉淀可复用代码、数据卡和实验报告，为课题组后续合成污染治理研究提供基础。

### 3.2 研究边界

- 不以提出新的表格生成模型为目标；
- 不要求证明新的模型坍缩理论；
- 不要求推导数据估值理论的封闭解；
- LLM 检测以零样本、少样本或弱标注范式为主，不进行大规模模型训练；
- 重点放在基准构建、实验协议和公平对比的严谨性上。



## 4. 形式化研究问题

### 4.1 基本设定

设真实表格数据分布为 \(D_{\mathrm{real}}\)，合成生成器 \(G\) 在训练数据上学习后诱导的合成分布为 \(D_{\mathrm{syn}}^{G}\)。一张表包含 \(d\) 个属性，属性集合为 \(\mathcal{F}=\{f_1,\ldots,f_d\}\)，每条记录 \(x\in\mathcal{X}\) 是混合类型向量。

对于记录 \(x\)，其来源标签定义为：

\[
y(x)=
\begin{cases}
0, & x\sim D_{\mathrm{real}},\\
1, & x\sim D_{\mathrm{syn}}^{G}.
\end{cases}
\]

给定污染比例 \(p\in[0,1]\)，混合分布定义为：

\[
D_{\mathrm{mix}}^{G,p}=(1-p)D_{\mathrm{real}}+pD_{\mathrm{syn}}^{G}.
\]

给定混合语料 \(C=\{x_i\}_{i=1}^{n}\)，真实污染比例为：

\[
p(C)=\frac{1}{n}\sum_{i=1}^{n}\mathbb{1}[y(x_i)=1].
\]

本课题围绕 \(D_{\mathrm{mix}}^{G,p}\) 研究三个任务。

### 4.2 任务一：样本级检测

**目标**：学习或构造打分函数 \(s:\mathcal{X}\rightarrow[0,1]\)，使 \(s(x)\) 表示记录 \(x\) 为合成记录的置信度。

**输入**：单条记录 \(x\)。  
**输出**：合成概率分数 \(s(x)\) 或标签 \(\hat{y}(x)\in\{0,1\}\)。  
**主指标**：AUROC。  
**辅助指标**：F1、Accuracy、TPR@FPR=5%、ECE。

低误报率下的 TPR 尤为重要。在真实数据治理场景中，将真实记录误判为合成记录将增加额外的人工核验成本。

### 4.3 任务二：语料级污染比例估计

**目标**：给定来源未知的混合语料 \(C\)，估计其中合成记录比例 \(\hat{p}\)。

**输入**：混合语料 \(C=\{x_i\}_{i=1}^{n}\)。  
**输出**：\(\hat{p}(C)\in[0,1]\)。  
**主指标**：

\[
\mathrm{MAE}=\frac{1}{K}\sum_{k=1}^{K}|\hat{p}_k-p_k|.
\]

该任务与样本级检测相关，但并不等价。即使单条记录难以准确分类，仍可能通过整体分数分布估计污染比例；反之，分类器校准不佳亦可能导致比例估计出现偏差。

### 4.4 任务三：估值影响分析

**目标**：分析不同污染比例下，混合数据集对下游模型效用和数据价值的影响。

设 \(V(D)\) 为数据集价值函数，可取为在 \(D\) 上训练下游模型后在真实测试集上的表现，例如 AUROC、F1 或 RMSE 的相反数。定义估值偏差：

\[
\Delta V(p)=V(D_{\mathrm{mix}}^{G,p})-V(D_{\mathrm{real}}).
\]

进一步可估计单条记录的近似 Data Shapley 值，比较真实记录与合成记录的贡献分布。

**下游任务设定**：估值影响实验需覆盖分类与回归两类下游任务，以便观察污染影响的任务依赖性。

| 下游任务 | 代表数据集 | 下游模型 | 效用指标 \(V(D)\) |
|----------|------------|----------|-------------------|
| 二分类 | Adult、Credit | Logistic Regression、XGBoost | 测试集 AUROC、F1 |
| 回归 | 选取含连续目标列的数据集（如 Boston Housing 或 Credit 中连续衍生目标） | Ridge、XGBoost Regressor | 测试集 RMSE、\(R^2\) |

本科阶段以 Adult/Credit 上的**分类任务**为主实验；回归任务作为扩展维度，至少在一个数据集上给出一条“污染比例 vs RMSE”曲线。

### 4.5 关键实验自变量

与说明书一致，实验需系统变化以下自变量：

| 自变量 | 取值 | 实验目的 |
|--------|------|----------|
| 合成占比 \(p\) | \(\{0\%, 5\%, 10\%, 25\%, 50\%, 75\%, 100\%\}\) | 难度曲线，重点关注低占比 5%–10% |
| 生成器 \(G\) | CTGAN、TVAE、GaussianCopula、LLM | 跨生成器泛化与难度分层 |
| 生成方式 | 全生成、条件生成 | 比较“从零生成”与“给定部分属性后补全”的检测难度 |
| 数据领域 | Adult（人口统计）、Credit（金融），医疗集为补充 | 跨领域泛化 |
| 下游任务 | 分类、回归 | 估值影响的任务依赖性 |

**生成方式说明**：

- **全生成**：生成器不指定条件列，从零采样完整记录；
- **条件生成**：固定 1–2 个关键类别列或数值列（如 Adult 的 `education`、`occupation`），由生成器补全其余字段。该设置更贴近“在已知部分真实信息基础上混入合成记录”的实际场景，检测难度通常也更高。

### 4.6 研究问题

本课题拟回答以下研究问题：

- **RQ1**：在 Adult、Credit 等公开表格数据集上，合成记录能否被统计方法、分类器和 LLM 方法有效检测？
- **RQ2**：污染比例较低（5%–10%）时，语料级污染比例能否被稳定估计？
- **RQ3**：检测方法是否具有跨生成器泛化能力，即训练时见 CTGAN，测试时是否仍能识别 TVAE、GaussianCopula 或 LLM 合成记录？
- **RQ4**：LLM 赋能检测相比传统统计和监督分类器是否有增益？其增益主要出现在哪些数据集或样本类型上？
- **RQ5**：合成污染比例增加时，下游效用和数据 Shapley 分布如何变化？
- **RQ6**：全生成与条件生成两种合成方式下，检测难度是否存在系统性差异？
- **RQ7**：合成污染对分类与回归两类下游任务的效用损失是否一致？



## 5. 初步算法思路

### 5.0 统一接口与实现约定

四类检测方法统一实现为 Python 类，接口口径与说明书保持一致：

```text
fit(D_train_real, D_train_syn=None)  # 零样本方法可跳过；密度/分类器方法按需调用
score(x) -> float                      # 样本级：合成概率分数，越高越像合成
predict(C) -> float                    # 语料级：估计混合语料中的合成占比 p̂
```

**预处理约定**（四类方法共用）：

1. 类别列：缺失填 `__MISSING__`，训练阶段学习合法取值集合；
2. 数值列：用 real-train 的均值/中位数填补缺失，再标准化；
3. 记录去重：合成记录与 real-train/real-test 完全一致的行在基准构建时剔除。

**语料级比例估计的通用流程**（四类方法共用骨架）：

1. 在已知 \(p\) 的校准集 \(\{C_k\}\) 上计算语料级统计量 \(T(C_k)\)（如分数均值、MMD、分位数向量）；
2. 拟合映射 \(f: T(C)\mapsto \hat{p}\)，优先采用线性回归或 isotonic regression；
3. 在测试混合集上输出 \(\hat{p}=f(T(C))\)，报告 MAE 及各档偏差方向。

本科阶段优先实现**均值估计 + isotonic 校准**两条路径，分位数匹配作为补充。

### 5.1 方法一：统计分布漂移检测

该类方法以 real-train 作为参考分布，不依赖合成训练集，属于零样本检测。

**样本级 `score(x)` 计算**：

对每条记录 \(x\)，逐列计算偏离分数后加权聚合：

| 列类型 | 单特征分数 | 含义 |
|--------|------------|------|
| 数值列 | \(-\log \hat{F}_j(x_j)\) 或 \(\|F_j(x_j)-0.5\|\) | \(\hat{F}_j\) 为 real-train 经验 CDF；越偏离中心分位，分数越高 |
| 类别列 | \(-\log \hat{P}_j(x_j)\) | \(\hat{P}_j\) 为 real-train 类别频率；低频/未见类别分数更高 |
| 缺失模式 | 列缺失指示向量与 real-train 缺失率向量的 L1 距离 | 合成数据可能系统性改变缺失模式 |

最终样本分数：

\[
s_{\mathrm{stat}}(x)=\frac{1}{|\mathcal{F}|}\sum_{j\in\mathcal{F}} w_j \cdot \mathrm{dev}_j(x_j),
\]

其中 \(w_j\) 默认均等，也可按列方差或信息增益加权。

**语料级 `predict(C)` 计算**：

1. 对数值化后的 real-train 与混合语料 \(C\)，计算 RBF-MMD：\(\mathrm{MMD}^2(C, D_{\mathrm{real}})\)；
2. 同时汇总 SDMetrics 风格指标：Column Shapes 均值、Column Pair Trends 均值、KS 统计量向量；
3. 在 \(\{p\in\{0\%,5\%,\ldots,100\%\}\}\) 的校准混合集上，用多变量回归或 isotonic 回归拟合 \(\mathrm{MMD}\rightarrow \hat{p}\)；
4. 输出 \(\hat{p}=f_{\mathrm{stat}}(\mathrm{MMD}(C), \text{其他统计量})\)。

**默认实现参数**：MMD 带宽用 median heuristic；校准集每档 \(p\) 至少 3 个随机种子。

**优点**：零样本、可解释、计算快。  
**局限**：列独立近似，难捕获高阶列间依赖；条件生成场景下边际分布差异可能变小。

### 5.2 方法二：密度/典型性检测

该类方法判断记录是否落在真实数据的高密度区域。CTGAN 在 SDV 实现中不直接暴露稳定的判别器分数，因此采用可复现的密度估计方案。

**主实现：GMM + 自编码器双通道**

| 子模块 | 训练数据 | 样本级分数 | 说明 |
|--------|----------|------------|------|
| GMM 通道 | 仅 real-train（数值化后） | \(s_{\mathrm{gmm}}(x)=-\log p_{\mathrm{gmm}}(x)\) | 分量数 \(K\in\{5,10,20\}\) 作为消融变量 |
| AE 通道 | 仅 real-train | \(s_{\mathrm{ae}}(x)=\|x-\hat{x}\|_2^2\) | 隐层维度 32/64，训练 50–100 epoch |
| 融合 | — | \(s_{\mathrm{dens}}(x)=\alpha s_{\mathrm{gmm}}+(1-\alpha)s_{\mathrm{ae}}\) | 默认 \(\alpha=0.5\)，在 real-val 上调优 |

**备选实现**（时间允许时二选一验证）：

- **KDE 通道**：对低维数值子空间做核密度估计，适合列数较少的医疗小数据集；
- **TVAE 重构误差**：在 real-train 上训练 TVAE，用 ELBO 重构误差作为典型性分数，与 GAN/VAE 生成器泛化实验形成呼应。

**语料级 `predict(C)` 计算**（补全密度法的比例估计路径）：

1. 对校准集 \(C_k\)（已知真值 \(p_k\)），计算语料级统计量：
   - 分数均值 \(\bar{s}_k=\frac{1}{|C_k|}\sum_{x\in C_k}s_{\mathrm{dens}}(x)\)；
   - 分数方差、90% 分位数；
   - 可选：real-train 与 \(C_k\) 的 GMM 平均对数似然差；
2. 在 \(\{(\bar{s}_k, p_k)\}\) 上拟合 isotonic 回归或分段线性映射 \(g\)；
3. 测试时输出 \(\hat{p}=g(\bar{s})\)，必要时加入方差项做多元回归修正。

**与说明书方法②的对应关系**：说明书中的“密度似然阈值”在本方案中具体化为 GMM 负对数似然与 AE 重构误差的融合分数；语料级则通过分数分布校准回归实现，而非直接读取生成器判别器。

### 5.3 方法三：训练式分类器检测

训练式分类器是阶段一已验证可行的主基线，适合作为其他方法的参照。

**训练数据构造**：

- 正类（合成）：syn-train 中随机采样 \(N\) 条；
- 负类（真实）：real-train 中随机采样 \(N\) 条；
- 默认 \(N=3000\)（与阶段一一致），类别平衡 1:1；
- 严格保证 syn-train 与 real-train 无记录重叠。

**特征工程**：

1. 类别列：one-hot 编码（高基数列用 target encoding，折内计算防泄漏）；
2. 数值列：`StandardScaler`，仅在 real-train+syn-train 上 fit；
3. 可选：列间交叉特征（如 `education × occupation`）仅用于 XGBoost 版本。

**模型与超参**：

| 模型 | 关键超参 | 角色 |
|------|----------|------|
| Logistic Regression | `C=1.0`, `max_iter=1000` | 阶段一基线，解释性强 |
| Random Forest | `n_estimators=200`, `max_depth=10` | 非线性基线 |
| XGBoost | `max_depth=6`, `learning_rate=0.1` | 主对比模型 |
| MLP | 2 层 `[128,64]`, dropout=0.2 | 深度基线（可选） |

**样本级输出**：\(s_{\mathrm{clf}}(x)=P(y=1\mid x)\)。

**语料级 `predict(C)`**：

1. 计算 \( \bar{s}=\frac{1}{|C|}\sum_{x\in C}s_{\mathrm{clf}}(x)\)；
2. 在已知 \(p\) 的校准混合集上，用 Platt scaling 或 isotonic regression 校准 \(\bar{s}\rightarrow \hat{p}\)；
3. 低污染场景（5%–10%）额外报告分位数匹配：将 \(C\) 的分数分布与“纯真实 / 纯合成”参考分布做混合权重估计。

阶段一结果：Adult + CTGAN（3000 真实 + 1000 合成，CTGAN 20 epochs）上 Logistic Regression AUROC = 0.7808。

**关键风险**：分类器可能过拟合 CTGAN 的局部痕迹。跨生成器（TVAE、GaussianCopula、LLM）和跨领域实验须单独报告，不宜仅考察同生成器结果。

### 5.4 方法四：LLM 赋能检测

参考 ZeroED 范式：LLM 负责小规模推理与弱标注，轻量模型负责规模化打分。

**两阶段流程**：

| 阶段 | 输入 | 输出 | 规模 |
|------|------|------|------|
| 阶段 A：LLM 推理 | schema + few-shot 真实样本 + 待测记录 | JSON `{label, confidence, reason}` | 小样本（数百条）验证 + 代表样本标注 |
| 阶段 B：弱监督扩展 | LLM 标注子集 + 全量特征 | 轻量分类器（LR/XGBoost） | 全量测试集 |

**记录序列化模板**（默认）：

```text
age = 39; education = Bachelors; occupation = Adm-clerical; hours-per-week = 40; income = <=50K
```

**Prompt 模板**：

```text
你是表格数据质量分析专家。下面是数据集 {dataset_name} 的字段说明：
{schema_description}

以下是从真实数据集中抽取的若干样例：
{real_examples}

请判断待测记录是否更可能是机器生成的合成记录。
请只输出 JSON：
{"label": "real/synthetic", "confidence": 0到1之间的小数, "reason": "简短理由"}

待测记录：
{record}
```

**实现细节**：

- LLM 候选：本地 Qwen2.5-1.5B/7B 或 API 模型，至少对比 1–2 个；
- few-shot 数：0 / 3 / 5 / 10（消融变量）；
- 输出后处理：正则提取 JSON，解析失败则重试 1 次，仍失败记为 `confidence=0.5` 并计入失败率；
- 样本级分数：直接使用 `confidence`（`synthetic` 标签）或阶段 B 分类器概率；
- 语料级 `predict(C)`：对 \(C\) 中每条记录调用 `score(x)` 后取均值，再经 isotonic 校准；若采用阶段 B，则与分类器方法共用校准流程。

LLM 方法不预设一定优于传统分类器；若在结构化表格上效果有限，应作为负结果报告并分析原因（字段短、模式单一、成本较高等）。

### 5.5 四类方法的语料级比例估计对照

| 方法 | 语料级统计量 \(T(C)\) | 校准方式 | 适用场景 |
|------|----------------------|----------|----------|
| 统计漂移 | MMD、Column Shapes/Pairs 均值 | 多变量回归 / isotonic | 零样本、无需合成训练集 |
| 密度/典型性 | 分数均值、方差、GMM 似然差 | isotonic / 分位数匹配 | 需密度模型，适合中等维度 |
| 训练式分类器 | 分数均值、分位数 | Platt / isotonic | 分数校准较好时最直接 |
| LLM 赋能 | 聚合 confidence 均值 | isotonic | 小样本验证后扩展 |

**本科默认策略**：所有方法均实现 isotonic 校准；分类器与 LLM 方法额外报告未校准的均值估计 \(\hat{p}=\bar{s}\) 作为对照。

### 5.6 估值影响分析

估值影响分析以实证为主，分数据集级与记录级两层。

**数据集级价值**：

\[
V(D)=\mathrm{Perf}(h_D, D_{\mathrm{test}}^{real}),
\]

其中 \(h_D\) 是在数据集 \(D\) 上训练的下游模型，\(D_{\mathrm{test}}^{real}\) 是固定真实测试集。

| 下游任务 | \(h_D\) | \(\mathrm{Perf}\) 指标 |
|----------|---------|------------------------|
| 分类 | LR / XGBoost Classifier | AUROC、F1 |
| 回归 | Ridge / XGBoost Regressor | RMSE（取负值或报告损失）、\(R^2\) |

**估值偏差**：\(\Delta V(p)=V(D_{\mathrm{mix}}^{G,p})-V(D_{\mathrm{real}})\)，报告“每 1% 合成污染带来的平均效用损失”。

**记录级价值**：

用 KNN-Shapley 或 leave-one-out 近似衡量单条记录对下游性能的贡献，比较真实记录与合成记录的 Shapley 分布（均值、分位数、KS 距离）。

**必须设置的三组对照**：

1. **追加式污染**：在 \(D_{\mathrm{real}}\) 上追加 \(m\) 条合成记录；
2. **等量真实对照**：追加 \(m\) 条额外真实记录（从 real-train 采样，不进入测试集）；
3. **替换式污染**：保持训练集大小不变，用 \(m\) 条合成记录替换等量真实记录。

只有同时报告 (2)(3)，方能区分“合成污染净效应”与“数据量变化效应”。

**因果忠实性分析（5d，优秀档扩展）**：时间允许时，分别在 \(D_{\mathrm{real}}\) 与 \(D_{\mathrm{syn}}\) 上用 PC / GES 算法学习因果图，比较结构汉明距离（SHD）、Precision、Recall，以检验合成数据是否保持变量间因果结构。

## 6. 对比算法整理

| 方法 | 类型 | 训练需求 | 样本级 `score(x)` | 语料级 `predict(C)` | 优点 | 风险 |
|------|------|----------|-------------------|---------------------|------|------|
| 统计分布漂移 | 零样本统计 | 仅需 real-train | CDF/频率偏离聚合 | MMD + 统计量 → isotonic 校准 | 可解释、低成本、无需合成标注 | 列独立近似，条件生成下边际差异小 |
| 密度/典型性检测 | 无监督 | 仅需 real-train | GMM 负似然 + AE 重构误差融合 | 分数均值/方差 → isotonic 校准 | 不绑定特定生成器，语料级路径明确 | 高维混合表格密度估计困难 |
| 训练式分类器 | 监督学习 | 需 real+syn 标注集 | \(P(y{=}1\mid x)\) | 分数均值 → Platt/isotonic 校准 | 阶段一已验证（AUROC 0.78） | 易过拟合生成器痕迹 |
| LLM 赋能检测 | 零样本/弱监督 | 可不训练；弱监督需 LLM 标注子集 | LLM confidence 或弱监督分类器概率 | 聚合 confidence → isotonic 校准 | 可利用语义先验，延伸 ZeroED 范式 | 成本高、输出不稳定、解析失败 |

**效率维度对比**：

| 方法 | 是否需训练 | 单条 `score(x)` 时延（目标量级） | 语料级额外开销 |
|------|------------|----------------------------------|----------------|
| 统计漂移 | 否 | < 1 ms | MMD 随语料规模线性增长 |
| 密度/典型性 | 是（GMM+AE） | 1–5 ms | 需预计算语料分数向量 |
| 训练式分类器 | 是 | < 1 ms（推理） | 训练一次性，推理快 |
| LLM 赋能 | 否/弱监督 | 0.5–5 s（视模型与 API） | 语料级需全量调用或弱监督扩展 |

| 生成器 | 类型 | 当前状态 | 用途 | 生成方式 |
|--------|------|----------|------|----------|

**LLM 生成器配置**：

- Prompt 输入：数据集 schema、字段取值范围、3–5 条真实样例；

- 参数：temperature=0.7–1.0，每数据集生成 1000–3000 条；
- 质量过滤：与 CTGAN/TVAE 共用同一套去重、去无效、SDMetrics 检查流程。

LLM 生成器在主实验中至少纳入**跨生成器泛化测试**；时间允许时在主表增加 LLM 列，形成“4 生成器 × 4 方法”的完整对比。

### 7.4 数据集构建协议

对每个真实数据集：

1. 固定随机种子，划分 real-train、real-val、real-test（如 70/15/15）；
2. 只用 real-train 训练生成器；
3. 由生成器产生 syn-train、syn-val、syn-test：
   - **全生成**：不指定条件列；
   - **条件生成**（CTGAN）：固定 `education`、`occupation` 等 1–2 个关键列，生成器补全其余字段；
4. 构造样本级标注集（每条记录标注 real=0 / syn=1）；
5. 按 \(p\in\{0\%,5\%,10\%,25\%,50\%,75\%,100\%\}\) 构造语料级混合集；
6. 每个比例至少 3 个随机种子重复；
7. **质量过滤**（与说明书一致）：
   - 去重：合成数据内部去重，剔除与 real-train/real-test 完全一致的行；
   - 去无效：数值越界、类别值不在定义域的记录剔除；
   - 统计检查：SDMetrics Overall Quality 应在合理区间（过低=生成失败，过高≈1.0=可能泄漏）；
8. 生成数据卡：来源、许可、字段、缺失率、生成参数、全生成/条件生成标记、统计摘要。

**专门泛化测试集**：

- 跨生成器：训练只见 CTGAN 合成，测试见 TVAE / GaussianCopula / **LLM** 合成；
- 跨领域：Adult 训练，Credit 测试（反向亦然）。

这一协议的核心是防止同源泄漏：用于训练生成器的真实记录，不能出现在最终检测测试集的真实部分里。



## 8. 测试方案

### 8.0 核心评测指标

| 任务 | 主指标 | 辅助指标 |
|------|--------|----------|
| 样本级检测 | AUROC | TPR@FPR=5%、F1、Accuracy、ECE |
| 语料级比例估计 | MAE \(\|\hat{p}-p\|\)（多档平均） | 各档误差曲线、偏差方向（高估/低估） |
| 估值影响 | \(\Delta V(p)\)、下游效用曲线 | Shapley 分布偏移（良好/优秀档）、因果图 SHD（优秀档加分） |
| 效率 | 单条 `score(x)` 时延、语料级吞吐 | 显存占用、是否需训练、训练耗时 |

### 8.1 主实验：方法总体对比

**设置**：

- 数据集：Adult、Credit；
- 生成器：CTGAN、TVAE、GaussianCopula（主表）；LLM 生成器纳入跨生成器测试，时间允许时加入主表；
- 生成方式：全生成（主表）；条件生成（CTGAN 子实验，见 §8.2）；
- 方法：统计分布漂移、密度/典型性检测、训练式分类器、LLM 赋能检测；
- 指标：样本级 AUROC、TPR@FPR=5%、F1、ECE；语料级 MAE；效率（单条时延、是否需训练）。

输出主表：

| 数据集 | 生成器 | 生成方式 | 方法 | AUROC | TPR@FPR=5% | F1 | MAE | 单条时延(ms) |
|--------|--------|----------|------|-------|------------|----|-----|--------------|

与说明书实验一对应：4 类方法 × 多种生成方式 × 2 个数据集，在样本级与语料级两任务上做统一对比。

### 8.2 检测难度曲线

按污染比例 \(p\) 绘制曲线：

- 样本级：不同方法在不同生成器上的 AUROC；
- 语料级：\(|\hat{p}-p|\) 随 \(p\) 的变化；
- 特别报告 5% 和 10% 低污染场景。

**生成方式子实验**（说明书关键自变量）：

- 对比 CTGAN 全生成与条件生成在相同 \(p\) 下的 AUROC 与 MAE；
- 预期：条件生成因边际分布更接近真实，检测难度通常更高。

### 8.3 泛化实验

**跨生成器**：

- 训练：real vs CTGAN；
- 测试：real vs TVAE / GaussianCopula / **LLM 生成**；
- 反向测试：real vs TVAE 训练，CTGAN / LLM 测试。

**跨领域**：

- Adult 训练，Credit 测试；
- Credit 训练，Adult 测试。

该实验旨在检验检测器是否仅记住了某一生成器的局部痕迹，而非识别“合成性”本身。

### 8.4 消融实验

**方法①②：参考模型/密度模型大小**

| 因素 | 取值 | 观察指标 |
|------|------|----------|
| GMM 分量数 \(K\) | 5、10、20 | AUROC、MAE、拟合耗时 |
| AE 隐层维度 | 32、64、128 | 重构误差分布、AUROC |
| MMD 带宽 | median heuristic、0.5×/2× 缩放 | 语料级 MAE |

**方法④：LLM 相关消融**

| 因素 | 取值 |
|------|------|
| few-shot 数 | 0、3、5、10 |
| 记录序列化模板 | 简单属性值、带字段说明、带统计摘要 |
| LLM 类型 | 本地小模型或 API 模型，至少 1–2 个 |
| 聚合方式 | 直接判别、LLM 弱标注 + 分类器 |

报告准确性、输出解析失败率、平均调用时延、token 成本与显存占用。

### 8.5 估值影响实验

| 子实验 | 做法 | 指标 | 档位 |
|--------|------|------|------|
| 5a 下游效用曲线 | 用 \(D_{\mathrm{mix}}^{G,p}\) 训练下游模型，在真实测试集评估 | 分类：AUROC/F1 vs \(p\)；回归：RMSE/\(R^2\) vs \(p\) | 必做 |
| 5b Shapley 偏移 | 比较真实记录与合成记录的 Shapley 分布 | 均值、分位数、KS 距离 | 良好/优秀 |
| 5c 估值偏差量化 | \(\Delta V(p)=V(D_{\mathrm{mix}}^{G,p})-V(D_{\mathrm{real}})\) | 每 1% 污染的效用损失 | 必做 |
| 5d 因果忠实性 | PC/GES 分别学 \(D_{\mathrm{real}}\) 与 \(D_{\mathrm{syn}}\) 因果图 | SHD、Precision、Recall | 优秀档加分 |

**对照实验**（必须同时报告）：

| 对照类型 | 做法 | 目的 |
|----------|------|------|
| 等量真实对照 | 混入等量真实样本 vs 混入等量合成样本 | 排除数据量混淆 |
| 替换式污染 | 保持训练集大小不变，用合成替换真实 | 量化净污染效应 |

**下游任务覆盖**：

- 分类（必做）：Adult、Credit 上训练 LR/XGBoost，报告 AUROC/F1 随 \(p\) 变化；
- 回归（扩展）：至少在一个含连续目标的数据集上报告 RMSE 随 \(p\) 变化，观察与分类结论是否一致。

若时间不足，至少完成 5a + 等量真实对照 + 替换式污染；Shapley（5b）对应良好档，因果分析（5d）对应优秀档加分项。

### 8.6 公平性与可复现要求

1. 统一 train/val/test 划分；
2. 固定随机种子并保存配置；
3. 所有方法使用相同测试集；
4. 不使用测试集调阈值；
5. 报告均值和标准差；
6. 保存生成器参数、数据卡和评估脚本；
7. 对负结果如实报告。

## 10. 风险与应对

| 风险 | 具体表现 | 应对策略 |
|------|----------|----------|
| 数据泄漏 | 生成器训练数据与测试真实数据同源 | 按源划分，先划分后生成 |
| 合成质量过差 | 检测结果虚高 | 用 SDMetrics 和规则过滤检查生成质量 |
| 分类器过拟合生成器 | 同生成器好，跨生成器差 | 必做跨生成器泛化 |
| LLM 效果不稳定 | 输出格式乱、成本高 | 小样本验证、严格 JSON 解析、弱标注扩展 |
| 估值实验混淆 | 数据量变化导致性能变化 | 替换式污染与等量真实对照 |
| 工作量过大 | 多数据集多方法无法全部完成 | 按说明书合格/良好/优秀档分层推进 |
