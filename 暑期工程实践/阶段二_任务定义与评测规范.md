# 阶段二：三条任务线的任务定义与评测规范

## 1. 文档目的

本文件固定毕业设计三条任务线的研究对象、输入输出、数据划分、实验协议和评价指标，作为后续基准构建、算法复现和研究方案写作的统一依据。

三条任务线不可混为一谈：

1. **样本级检测**判断单条记录是否为合成数据；
2. **语料级污染比例估计**判断一批记录中合成数据所占比例；
3. **估值影响分析**研究不同合成污染条件对下游效用和数据价值的影响。

三者形成“识别记录 - 量化污染 - 分析后果”的递进关系，但分别具有独立的研究问题、算法和评价指标。

## 2. 统一符号与基本设定

设真实表格数据总体分布为 (P_r(X,Y))，其中 (X) 表示输入属性，(Y) 表示可选的下游任务标签。真实数据集为：

\[
D_r=\{(x_i,y_i)\}_{i=1}^{n}.
\]

使用生成器 (G\in\mathcal{G}) 在真实训练集上拟合后产生合成数据，其分布记为 (P_s^G(X,Y))，合成数据集为：

\[
D_s^G=\{(\tilde{x}_i,\tilde{y}_i)\}_{i=1}^{m}.
\]

来源标签记为 (z\in\{0,1\})：

- (z=0)：真实记录；
- (z=1)：合成记录。

合成污染比例为 (p\in[0,1])。固定规模的替换式混合语料定义为：

\[
C_{G,p}\sim(1-p)P_r+pP_s^G.
\]

核心污染比例设为：

\[
\mathcal{P}=\{0,0.05,0.10,0.25,0.50,0.75,1.00\}.
\]

## 3. 统一数据划分与防泄漏规则

### 3.1 真实数据划分

每个真实数据集先固定划分为：

- `real_train`：训练生成器、拟合检测器允许使用的真实部分；
- `real_validation`：检测器调参、阈值选择、概率校准和比例估计器训练；
- `real_test`：仅用于最终评价和下游效用测试。

默认比例为 70%/15%/15%；若直接论文使用特定官方划分，则同时保存“本文统一划分”和“论文复现划分”。

### 3.2 合成数据划分

生成器只能在 `real_train` 上训练。生成结果按用途隔离为：

- `syn_train`：监督检测器训练；
- `syn_validation`：检测器调参与比例估计器校准；
- `syn_test`：最终样本级检测和语料级估计测试。

同一条合成记录不能跨集合出现。合成记录与真实记录完全重合时标记并报告；因明确复制或泄漏产生的记录从正式基准中剔除，同时保留审计日志。

### 3.3 重复实验

- 正式主结果至少使用 5 个随机种子；
- 保存数据划分索引、生成器种子、检测器种子和混合语料种子；
- 报告均值、标准差，关键结果补充 95% 置信区间；
- 不允许只选择表现最好的种子。

## 4. 任务线一：样本级合成记录检测

### 4.1 任务目标

给定单条表格记录 (x)，判断其来源是真实数据还是生成器产生的合成数据，并输出连续的合成分数。

### 4.2 输入与输出

输入：

- 单条记录 (x=(x_1,\ldots,x_d))；
- 根据赛道允许使用的辅助信息，如 schema、真实训练集或带来源标签的训练集。

输出：

\[
s(x)\in[0,1],
\]

其中分数越高表示记录越可能是合成记录。可选离散输出为：

\[
\hat z=\mathbb{I}[s(x)\ge\tau].
\]

阈值 (	au) 只能在验证集上选择。

### 4.3 算法赛道

为避免使用信息不同的方法被不公平比较，分为：

| 赛道 | 允许使用的信息 | 代表方法 |
|---|---|---|
| 无监督/仅真实参考 | `real_train`，无合成标签 | 密度、异常、统计典型性方法 |
| 监督同生成器 | `real_train` + 已知生成器的 `syn_train` | C2ST-LR、C2ST-XGBoost |
| 跨生成器 | 训练只见部分生成器，测试为未见生成器 | C2ST、3-gram LR、Transformer |
| 跨表 | 训练表与测试表 schema 不重合 | 3-gram LR、表无关 Transformer |
| 零样本/LLM | schema、任务说明和规定数量的真实示例 | LLM 直接判断 |
| 弱监督/LLM | LLM 标注规定规模的训练子集 | LLM 弱标注 + 轻量分类器 |

同一赛道内进行主排名；跨赛道结果用于分析“额外监督信息换来的性能增益”。

### 4.4 评测协议

| 协议 | 训练条件 | 测试条件 | 研究目的 |
|---|---|---|---|
| P1 同表同生成器 | 表和生成器均可见 | 相同表、相同生成器的新记录 | 测量检测性能上限 |
| P2 同表跨生成器 | 测试表可见，测试生成器不可见 | 相同表、未见生成器 | 检验是否记忆生成器痕迹 |
| P3 跨表 | 测试生成器可见或混合 | 未见 schema 的表 | 检验表无关表示能力 |
| P4 完全迁移 | 部分表和生成器 | 表与生成器均未见 | 最严格真实部署模拟 |

普通 one-hot LR/XGBoost 只能用于固定 schema 的 P1/P2；只有采用统一表无关表示后才能参加 P3/P4。

### 4.5 评价指标

主指标：

- AUROC：衡量真实/合成排序能力；
- AUPRC：低污染、类别不平衡时的关键指标；
- TPR@FPR=5%：严格控制真实记录误报时的合成召回率。

辅助指标：

- F1、Precision、Recall、Accuracy；
- ECE 和 Brier Score：概率校准；
- 训练时间、单条推理时间、吞吐、峰值内存/显存；
- 跨生成器性能下降和跨表性能下降。

注意：AUROC理论上对类别先验相对不敏感，不将“AUROC随污染比例变化”作为主要低污染曲线；低污染场景优先报告 AUPRC、Precision、F1 和 TPR@固定FPR。

### 4.6 最小验收范围

- 数据集：Adult、Credit；
- 生成器：CTGAN、TVAE、GaussianCopula；
- 方法：C2ST-LR、C2ST-XGBoost、Character 3-gram + LR、至少一种 Transformer 直接基线；
- 协议：P1、P2；
- 扩展：6 表 P3、Datum-wise Transformer、P4、LLM。

## 5. 任务线二：语料级污染比例估计

### 5.1 任务目标

给定一批来源未知的混合表格记录 (C=\{x_i\}_{i=1}^{n})，估计其中合成记录的比例 (p)。

该任务在相关领域中对应 quantification、class prevalence estimation、class prior estimation 或 mixture proportion estimation。

### 5.2 输入与输出

输入：

- 混合语料 (C)；
- 可选的样本级检测分数 (S_C=\{s(x_i)\}_{i=1}^{n})；
- 根据赛道允许使用的真实/合成参考分数分布或已知比例校准语料。

输出：

\[
\hat p=q(C)\in[0,1].
\]

### 5.3 与样本级检测的关系

两层接口明确分离：

\[
\text{Detector}:x\mapsto s(x),
\]

\[
\text{Quantifier}:\{s(x_i)\}_{i=1}^{n}\mapsto\hat p.
\]

一个样本级检测器可以搭配多个比例估计器。样本级 AUROC 高不保证比例 MAE 低，因为分数校准、类别先验变化和误报累积都会影响比例估计。

### 5.4 算法赛道

| 类别 | 代表方法 | 输入 |
|---|---|---|
| 计数类 | CC、PCC | 预测标签或概率 |
| 误差修正类 | AC、PACC | 预测结果 + 验证集混淆信息 |
| 先验估计类 | EMQ | 分类器后验概率 |
| 分布匹配类 | HDy、DyS、KDEy | 真实/合成/混合语料分数分布 |
| 本文校准基线 | Isotonic-to-p | 已知比例校准语料的统计量 |
| 无逐条检测统计法 | MMD-to-p | 真实参考集与混合语料 |

### 5.5 数据构造与隔离

每份语料默认固定规模 (n=1000)，按 (mathcal{P}) 中各比例构造。正式结果至少 5 个种子。

必须分离：

- `quantification_calibration`：训练/校准比例估计器；
- `quantification_test`：最终报告 MAE；

二者不得共享记录或混合随机种子。跨生成器实验中，校准阶段不得接触测试生成器。

### 5.6 评测协议

| 协议 | 校准与训练 | 测试 | 研究目的 |
|---|---|---|---|
| Q1 同分布估计 | 已知表、已知生成器 | 新混合集 | 基本比例估计能力 |
| Q2 跨比例 | 只用部分比例校准 | 未见比例 | 检验插值/外推稳定性 |
| Q3 跨生成器 | 已知生成器校准 | 未见生成器 | 检验检测分数分布变化 |
| Q4 跨表 | 已知表校准 | 未见表 | 检验 schema 变化下估计能力 |

### 5.7 评价指标

主指标：

\[
\mathrm{MAE}=\frac{1}{K}\sum_{k=1}^{K}|\hat p_k-p_k|.
\]

辅助指标：

- RMSE；
- Bias (=K^{-1}\sum_k(\hat p_k-p_k))；
- 5%和10%低污染场景的绝对误差；
- 各比例误差曲线和 95% 置信区间；
- 语料规模变化下的误差；
- 估计耗时。

### 5.8 最小验收范围

- 检测器：C2ST-LR、C2ST-XGBoost、3-gram LR；
- 估计器：CC、PACC、EMQ或HDy、Isotonic-to-p；
- 协议：Q1、Q3；
- 重点比例：5%、10%；
- 扩展：KDEy/DyS、Q2/Q4、不同语料规模。

## 6. 任务线三：合成污染的估值影响分析

### 6.1 任务目标

研究合成生成器类型 (G)、污染比例 (p) 和污染方式如何影响下游模型在真实测试分布上的效用，以及真实/合成训练记录的数据价值。

本任务不以“检测准确率排名”为核心，而以污染条件和估值方法的受控对照实验为核心。

### 6.2 输入与输出

输入：

- 纯真实训练集；
- 不同 (G,p) 构造的污染训练集；
- 固定真实测试集；
- 下游学习算法与价值函数。

输出：

- 数据集级效用/价值 (V(D))；
- 污染相对纯真实数据的价值变化 (Delta V_G(p))；
- 可选的记录级价值 (phi_i)；
- 真实/合成记录价值分布及治理后的效用恢复。

### 6.3 污染方式与必要对照

| 条件 | 构造方式 | 目的 |
|---|---|---|
| 纯真实基线 | 只使用真实训练集 | 价值参照点 |
| 等量真实追加 | 追加真实记录 | 测量单纯增加数据量的收益 |
| 合成追加 | 追加合成记录 | 观察合成增量的总效应 |
| 替换式污染 | 合成替换等量真实记录，总规模固定 | 隔离净污染效应 |
| 随机替换对照 | 随机移除/替换相同数量记录 | 检验效应是否来自选择偏差 |

正式主结论优先使用替换式污染，避免把训练数据量变化误认为污染影响。

### 6.4 数据集级价值

固定真实测试集 (D_{test}^{real})。在训练集 (D) 上训练下游模型 (h_D)，定义：

\[
V(D)=\mathrm{Perf}(h_D,D_{test}^{real}).
\]

污染影响为：

\[
\Delta V_G(p)=V(D_{mix}^{G,p})-V(D_{real}).
\]

分类任务使用 AUROC/AUPRC/F1；回归任务使用负 RMSE 或单独报告 RMSE、(R^2)。

### 6.5 记录级价值方法

代表方法包括：

- Leave-one-out：简单但忽略组合贡献；
- Data Shapley/TMC-Shapley：经典数据估值方法；
- KNN-Shapley：适合可计算的本科主实验；
- Data Banzhaf：稳健性扩展；
- Data-OOB、Influence Function 等可作为进一步对照。

记录级比较至少报告真实记录与合成记录价值的均值、中位数、分位数、负值比例和分布距离。

### 6.6 评测问题

1. (p) 增加时下游效用是否单调下降，是否存在无明显损失区间；
2. 不同生成器造成的效用损失是否一致；
3. 合成记录的平均价值是否低于真实记录，是否存在正价值合成记录；
4. 检测器分数与记录价值是否相关；
5. 按检测分数过滤/降权是否优于随机治理，并能恢复多少效用。

### 6.7 评价指标

- 下游效用曲线 (V(D_{mix}^{G,p}))；
- 价值偏差 (Delta V_G(p))；
- 单位污染斜率或分段斜率；
- 真实/合成记录价值分布差异；
- Spearman 相关：检测分数与负价值/价值排序；
- 治理恢复率：相对于理想标签治理上限恢复的效用比例；
- 估值计算时间和稳定性。

### 6.8 最小验收范围

- Adult、Credit 分类任务；
- 下游模型：LR、XGBoost；
- CTGAN、TVAE、GaussianCopula；
- 纯真实、等量真实追加、合成追加、替换式污染；
- 数据集级 (Delta V_G(p)) 必做；
- KNN-Shapley 作为记录级优先扩展；
- Data Banzhaf、因果忠实性和回归任务为加分项。

## 7. 三条任务线的统一关系

| 层级 | 核心问题 | 算法输出 | 主指标 |
|---|---|---|---|
| 样本级检测 | 哪条记录是合成的？ | (s(x)) | AUROC、AUPRC、TPR@FPR |
| 语料级估计 | 一批数据中合成比例是多少？ | (hat p) | MAE、RMSE、Bias |
| 估值影响 | 污染造成了什么后果？ | (Delta V(p),\phi_i) | 效用变化、价值分布、治理恢复率 |

可选治理闭环为：

\[
x\xrightarrow{Detector}s(x)\xrightarrow{Quantifier}\hat p
\xrightarrow{Filter/Reweight}D_{cleaned}\xrightarrow{Valuation}V(D_{cleaned}).
\]

治理闭环是加分实验，不取代三条任务线各自的独立评价。

## 8. 基准第一版固定范围

### 8.1 主任务轨道

- 数据集：Adult、Default of Credit Card Clients；
- 生成器：GaussianCopula、CTGAN、TVAE；
- 污染比例：0%、5%、10%、25%、50%、75%、100%；
- 重复：5 个随机种子；
- 任务：样本级、语料级、估值影响全部覆盖。

### 8.2 跨表复现轨道

- 至少 6 张不同 schema 的公开表；
- 生成器优先 CTGAN、TVAE，随后加入直接论文所用生成器；
- 只承担样本级跨表/跨生成器复现，避免将估值实验无限扩展；
- 采用按 table 分组的训练测试隔离。

## 9. 正式结果表结构

最终至少形成：

1. 样本级同表/跨生成器主结果表；
2. 样本级跨表/完全迁移结果表；
3. 检测器 × 比例估计器的 MAE 表；
4. 5%/10%低污染详细表；
5. 污染比例 - 下游效用曲线；
6. 真实/合成记录价值分布表；
7. 方法效率与监督信息需求表。
