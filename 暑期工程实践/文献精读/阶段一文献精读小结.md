# 阶段一文献精读小结
## 1. CTGAN：Modeling Tabular Data using Conditional GAN
> Xu L., Skoularidou M., Cuesta-Infante A., Veeramachaneni K. *Modeling Tabular Data using Conditional GAN*. NeurIPS 2019.

- 解决什么问题：该文献关注如何生成高质量的合成表格数据。表格数据存在三个主要问题，即同时包含连续变量列和离散变量列、连续列往往呈现非高斯多峰分布、离散列高度不平衡，导致普通 GAN 难以直接建模真实表格数据的联合分布。

- 核心思路：CTGAN 通过 mode-specific normalization 处理连续列多峰分布，并结合conditional generator与training-by-sampling缓解离散类别不平衡，从而提升GAN在混合类型表格数据上的生成质量。

- 可借鉴点：CTGAN是本课题构造合成污染基准的核心生成器之一。它可以用于从真实表格数据中生成合成记录，再与真实记录按不同比例混合，形成“真实+合成”的污染数据集。同时，论文中指出的少数类别丢失、多峰分布难建模、变量关系难保真表格生成难点，也是合成数据可能留下检测痕迹的来源。因此，本题可以利用CTGAN生成一类代表性的GAN式合成污染，并进一步检验统计方法、分类器和LLM是否能识别这种污染。

## 2. TVAE：Synthesizing Tabular Data using GAN and VAE
> Xu L., et al. *Synthesizing Tabular Data using GAN and VAE (TVAE)*. NeurIPS 2019 workshop.

- 解决什么问题：TVAE 研究如何将 VAE 适配到混合类型表格数据生成中，使模型能够同时处理连续列、离散列以及复杂的表格分布。

- 核心思路：TVAE以VAE的编码器-解码器框架为基础，通过表格数据预处理、混合类型输出分布建模和ELBO目标优化，使模型能够从潜在空间采样并解码生成连续列与离散列并存的合成表格记录。

- 可借鉴点：TVAE 是本课题构造合成污染基准的重要VAE路线生成器。它与CTGAN的生成机制不同，适合用于跨生成器泛化实验，检验检测器是否只学习到某个生成器的局部痕迹，从而衡量检测方法的稳健性；同时也可用于比较不同合成机制对下游模型效用和数据估值的影响。

## 3. DataSynthesizer：Privacy-Preserving Synthetic Datasets
> Ping H., Stoyanovich J., Howe B. *DataSynthesizer: Privacy-Preserving Synthetic Datasets*. SSDBM 2017.

- 解决什么问题：该文献关注在隐私、法律和数据共享协议受限的场景下，如何生成一份结构和统计特征类似于原始数据、但不直接暴露真实个体记录的合成数据集。

- 核心思路：DataSynthesizer通过DataDescriber从原始表格中学习带差分隐私保护的数据摘要，再由DataGenerator从摘要中采样生成合成数据，并用ModelInspector比较真实数据和合成数据的统计相似性。

- 可借鉴点：DataSynthesizer可作为本课题中“早期统计型合成器”的代表。相比CTGAN/TVAE等深度生成模型，它使用直方图、频率分布和 Bayesian network建模表格数据，适合帮助本题构造另一类合成污染来源。论文中的ModelInspector也提供了统计检测基线的启发，例如比较单列分布、KL divergence、属性相关性和Bayesian network结构。此外，该文献强调隐私与效用之间的权衡，这也能为本题后续分析合成污染对下游效用和数据价值的影响提供背景。

## 4. General and Specific Utility Measures for Synthetic Data
> Snoke J., Raab G. M., Nowok B., Dibben C., Slavković A. *General and Specific Utility Measures for Synthetic Data*. Journal of the Royal Statistical Society: Series A, 2018.

- 解决什么问题：该文献研究如何评价合成数据是否有用。合成数据的目标是在保护隐私的同时保留足够的统计分布和分析价值。因此论文区分了general utility（关注合成数据整体分布是否接近真实数据）和specific utility（关注特定分析任务在合成数据上得到的结论是否接近真实数据）。

- 核心思路：论文用propensity score mean-squared error（pMSE）衡量真实数据和合成数据的整体可区分性，并用置信区间重叠、标准化系数差异等指标衡量具体分析任务的一致性。

- 可借鉴点：这篇论文可为本题的检测基线提供理论来源。pMSE的基本做法是把真实数据和合成数据合并，训练分类器判断每条记录来自真实数据还是合成数据；若分类器难以区分，说明合成数据与真实数据更相似；若容易区分，则说明合成数据留下了可检测痕迹。本题的样本级污染检测可以看作把这一思路反过来，即利用real-vs-synthetic可区分性检测污染。同时，specific utility的思想也可用于分析不同污染比例下下游模型性能、置信区间或评价指标是否发生变化。



## 5. A Comprehensive Survey of Synthetic Tabular Data Generation
> Shi R. S., Wang Y., Du M., Shen X., Chang Y., Wang X. *A Comprehensive Survey of Synthetic Tabular Data Generation*. arXiv 2025.

- 解决什么问题：该综述系统梳理合成表格数据生成领域的方法、流程、评估方式、应用场景和未来挑战，把传统方法、扩散模型和LLM-based方法放在统一框架下比较，补充近年来扩散模型和大语言模型在表格生成中的进展。

- 核心思路：该综述将合成表格数据生成方法划分为传统生成方法、扩散模型方法和 LLM-based 方法，并从生成、后处理、评估、应用和未来方向多个层面总结完整技术管线。

- 可借鉴点：这篇综述可作为本题文献综述的参考。它说明 CTGAN/TVAE 是经典起点，但合成表格数据生成已经扩展到 TabDDPM、TabDiff、TabSyn、GReaT、TabuLa、AIGT等扩散模型和LLM方法。综述中总结的数据量小、类别不平衡、缺失值、混合类型、复杂依赖、非高斯分布等表格生成难点同样是合成污染可能被检测出来的来源。综述涵盖的ML efficiency、fidelity、alignment 和 privacy等评价框架可帮助本题设计更完整的数据卡、评估指标和跨生成器泛化实验。

## 6. AI models collapse when trained on recursively generated data
> Shumailov I., Shumaylov Z., Zhao Y., Papernot N., Anderson R., Gal Y. *AI models collapse when trained on recursively generated data*. Nature, 2024.

- 解决什么问题：该文献研究当生成模型不断使用前代模型生成的数据进行训练时会发生的情况。论文指出，如果模型生成内容大量混入后续训练数据，模型会逐渐遗忘真实数据分布，尤其是长尾和低概率事件，最终出现不可逆的分布退化，即model collapse。

- 核心思路：模型在合成数据上递归训练会使得采样误差、模型表达误差和优化误差逐代累积，导致真实分布尾部消失、方差缩小，并最终引发模型坍缩。

- 可借鉴点：这篇论文解释了本课题展开研究的动机和重要性。论文中描述的情况具体到表格场景即为：如果合成表格数据混入真实训练集，下游模型可能逐渐学习到被压缩、被平滑或带有虚假相关性的分布。而在表格数据中，少数类别和长尾组合往往非常重要，合成数据污染可能削弱这些信息。因此，本题提出在表格数据进入训练前，检测其中是否混入合成数据，并估计污染比例，正是对模型坍缩风险的回应。



## 7. ZeroED：Hybrid Zero-Shot Error Detection Through Large Language Model Reasoning
> Ni W., Zhang K., Miao X., Zhao X., Wu Y., Wang Y., Yin J. *ZeroED: Hybrid Zero-Shot Error Detection Through Large Language Model Reasoning*. ICDE 2025.

- 解决什么问题：ZeroED研究如何在没有人工规则和人工标签的情况下检测表格数据错误。传统错误检测方法依赖人工定义约束或人工标注，成本较高；直接使用LLM 逐条判断又容易缺少全局数据上下文，并且同样存在成本过大的问题。

- 核心思路：ZeroED将LLM推理与传统机器学习流程结合，利用LLM生成错误原因感知特征和检测指标工具，对聚类选出的代表样本而非全部数据进行标注，再通过标签传播、错误增强和分类器训练完成大规模表格错误检测。

- 可借鉴点：本题虽然检测对象不局限于“错误单元格”，但可以借鉴ZeroED的一些关键思路：
  1. 将表格记录序列化为属性-值文本，使LLM能理解schema和记录内容；
  2. 在prompt中加入字段说明、真实样例和检测任务说明，让LLM判断记录是否不像真实数据；
  3. 使用代表性采样降低LLM调用成本；
  4. 将 LLM 作为标注器或特征生成器，再训练轻量分类器进行批量检测。

## 8. Data Shapley：Equitable Valuation of Data for Machine Learning
> Ghorbani A., Zou J. *Data Shapley: Equitable Valuation of Data for Machine Learning*. ICML 2019.

- 解决什么问题：该文献研究如何公平量化单条训练数据对机器学习模型性能的贡献。传统leave-one-out方法只考察删除单条数据对完整训练集性能的影响，难以刻画数据之间复杂的组合贡献，可能低估有副本、互补或交互作用的数据价值。

- 核心思路：Data Shapley将每条训练数据视为合作博弈中的参与者，用 Shapley value衡量其在不同数据子集中的平均边际贡献，并通过蒙特卡洛、截断蒙特卡洛和梯度近似等方法降低计算成本。

- 可借鉴点：Data Shapley可以作为估值影响分析的基础工具，分析混入合成数据后数据集价值如何变化。本题可以先用下游效用作为数据集价值函数，例如用混合数据训练分类器并在真实测试集上评估AUROC/F1，再观察污染比例p增加时价值函数的变化；而后可以计算真实记录和合成记录的近似Shapley值分布，比较合成记录是否系统性低价值或负价值。
