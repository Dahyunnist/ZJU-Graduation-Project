## 3. 直接相关性分层

### 3.1 任务线一：样本级检测

|层级|文献/算法|判断|
|---|---|---|
|直接核心|D1、D2、D3|研究对象、输入输出和部署问题与本课题一致。必须精读和复现。|
|直接但同表/诊断|D5 XGBoost检测、D7 XAI检测解释|明确研究真实/合成表格区分，但不解决未知schema；应作为同表强基线和解释模块。|
|方法学基础|D4 C2ST、D6 pMSE|为真实/合成可区分性提供理论或统计量，但不是跨表专用算法。|
|领域应用扩展|Taloni等，JAMA Ophthalmology 2025|检测LLM伪造医学数据集，使用末位数字、相关性、分布形态和临床规则；对象更偏整表取证，不是通用逐行检测器。可引用，不作为主排行算法。|

### 3.2 任务线二：语料级污染比例估计

目前未检出一篇已正式发表的论文专门以“合成表格污染率”为应用名称提出算法；但把合成记为正类后，本课题与binary quantification/class prevalence estimation在输入输出上同构，因此Q1–Q10是**任务定义直接相关、应用领域间接相关**。

必须覆盖的算法谱系为：

- 最弱但必要：CC、PCC。
- 经典校正：ACC、PACC、EMQ/SLD。
- 经典分布匹配：HDy、DyS、Median Sweep。
- 较新强方法：KDEy、Continuous Sweep。
- 压力测试依据：dataset shift系统实验。

HDy原始论文必须引用，但出版社全文不开放；算法可以通过QuaPy跑通。KDEy已在本轮补入。2026-07-06出现的 *Geometry-Aware Bayesian Quantification via Compositional Data Analysis* 是非常新的预印本，主要解决多类后验单纯形几何；当前二分类主任务暂不强制复现，若扩展为“真实+多个生成器来源比例”则应纳入。

### 3.3 任务线三：估值影响分析

截至复核日，未检出成熟论文直接把“合成表格污染记录”作为对象，同时完成记录级数据估值和污染影响比较。因此这里必须明确组合两类工作：

- V1–V4是通用数据估值算法，方法直接、应用间接。
- V5–V8及V7推断效用论文直接说明合成数据会怎样影响模型或统计结论，但不是记录级估值算法。

任务线三真正属于本课题的贡献，是在统一的真实/合成混合数据上，把KNN-Shapley、Data-OOB等价值方法与污染率—下游效用曲线结合。ICML 2025的Collapse or Thrive已补入，用于区分replacement、accumulation和固定预算抽样。

## 4. 检出但不应误列为主对比算法的方向

1. **水印检测**：RINTAW、TAB-DRW、TableMark等需要生成阶段或后处理阶段主动嵌入密钥。它们回答“带水印数据能否验证来源”，与本课题“未知来源、无水印的被动检测”假设不同。可在相关工作中单列，不进入主排行榜。
2. **科学表格取证**：TAB-AUDIT面向论文中的科学表格内容/结构取证，不等于结构化数据库中的逐行合成记录检测。
3. **生成模型**：CTGAN、TVAE、TabDDPM、TabSyn、ARF等负责制造污染样本，是数据条件而非检测算法。
4. **合成数据质量框架**：SDMetrics、FEST及一般保真度/隐私度指标可作为基准模块，但不能替代三条任务线的对比算法。
5. **文本/图像检测与污染论文**：除非方法能自然迁移到结构化表格，否则只能作为背景，不应凑进“直接相关算法”数量。
