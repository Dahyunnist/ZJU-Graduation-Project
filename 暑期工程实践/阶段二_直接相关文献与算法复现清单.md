## 1. 检索口径与纳入规则

本课题的对象是“真实表格数据中混入合成记录后，如何检测、估计污染比例并分析其对数据价值/模型效用的影响”。据此将文献分为三类：

1. **A类——直接相关**：明确研究合成表格记录检测、跨表/跨生成器检测，或可直接输出合成记录比例的方法。
2. **B类——方法学直接支撑**：虽然不是为合成表格污染提出，但其任务定义与本课题完全同构，如二样本分类检验、量化学习（class prevalence estimation）、数据估值。
3. **C类——问题动机或影响证据**：解释合成数据递归训练、推断效用或模型退化，但本身不是检测器或估值算法。

优先纳入正式期刊/会议论文，其次纳入尚无正式版本但高度相关的预印本；综述只用于建立谱系，不能替代原始算法论文。检索入口包括 ACM DL、IEEE Xplore、SpringerLink、PMLR、PVLDB、ACL Anthology、AAAI Digital Library、OpenReview、JMLR 和 arXiv，并进行了关键词组合、参考文献回溯和被引文献追踪。

核心检索式包括：`synthetic tabular data detection`、`cross-table synthetic detection`、`classifier two-sample test tabular synthetic`、`quantification learning class prevalence estimation dataset shift`、`synthetic data contamination proportion estimation`、`data valuation synthetic data model utility`、`model collapse synthetic training data`。

## 3. 任务线二：语料级污染比例估计

目标不是判断每条记录，而是对一个无标签混合集合直接估计合成记录占比。其标准学术名称是 **quantification / class prevalence estimation**。样本级检测器可以提供分数，但“逐条分类后计数”只是最弱的 CC/PCC 基线；还需使用专门校正分布偏移的量化算法。

|---|---|---|---|---|
|Q1|B；经典奠基|Forman，[Quantifying Counts and Costs via Classification](https://doi.org/10.1007/s10618-008-0097-y)，DMKD 2008|系统比较 CC、Adjusted Count、阈值选择、Median Sweep和混合模型，说明高分类准确率不保证比例估计准确。|复现CC、ACC、Median Sweep；优先调用QuaPy并核对公式。|
|Q2|B；概率校正经典|Bella 等，[Quantification via Probability Estimators](https://doi.org/10.1109/ICDM.2010.75)，ICDM 2010|用个体后验概率平均得到PCC，再以验证集软混淆率校正得到PACC，减少硬阈值造成的信息损失。|PCC/PACC均为必复现基础线。|

|Q4|B；强分布匹配方法|Maletzke 等，[DyS: A Framework for Mixture Models in Quantification](https://doi.org/10.1609/aaai.v33i01.33014552)，AAAI 2019|在分类器分数空间中，把测试分布匹配为正负类分布的混合，搜索最优占比；可组合多种直方图距离。|**DyS必复现**，并与HDy一并比较。|
|Q5|B；实验基础设施|Moreo 等，[QuaPy: A Python-Based Framework for Quantification](https://doi.org/10.1145/3459637.3482015)，CIKM 2021|提供量化算法、人工流行率协议、误差指标和统一实验接口，是任务线二可复现性的主要工程基础。|官方代码：[QuaPy](https://github.com/HLT-ISTI/QuaPy)；固定版本、保存配置。|
|Q6|B；谱系综述|González 等，[A Review on Quantification Learning](https://doi.org/10.1145/3117807)，ACM Computing Surveys 2017|整理分类校正、分布匹配、直接优化等方法，明确量化与分类是不同目标。|不作为算法对比项；用于方法分类和公式核验。|
|Q7|B；大规模比较研究|Schumacher 等，[A Comparative Evaluation of Quantification Methods](https://jmlr.org/papers/v26/21-0241.html)，JMLR 2025|在大量数据集上统一比较24种方法，显示不存在绝对统治者；为选择经典与强基线提供证据。|据其结果优先加入Median Sweep、DyS、HDy、EMQ/SLD等。|

## 5. 需要跑通的算法：分层清单

“跑通”不是能启动仓库，而是：能在固定数据划分上训练和推断；能生成论文规定的主要指标；保存环境、随机种子、超参数和日志；至少完成一个小规模结果与论文趋势核对；最后接入统一基准。

### 第一优先级：论文必须出现、代码必须跑通

1. 样本检测：C2ST-LR、C2ST-XGBoost、字符3-gram+LR、扁平文本Transformer、table-wise/table Transformer、datum-wise Transformer核心版。
2. 比例估计：CC、PCC、ACC、PACC、EMQ/SLD、HDy、DyS、Median Sweep；检测器分数统一复用，量化器的校准集必须与检测器训练集隔离。
3. 估值分析：KNN-Shapley、Data-OOB；另做“污染比例—下游性能”效用曲线，这是第三条任务线不可省略的非估值基线。

### 第二优先级：SOTA/稳健性增强

1. 样本检测：带table adaptation的datum-wise Transformer；XAI诊断模块。
2. 比例估计：Continuous Sweep（2026新）、KDEy、Forman Mixture Model/TSMax；在纯prior shift、covariate shift、concept shift下分别测试。
3. 估值分析：TMC-Shapley、Data Banzhaf；计算预算不足时在小数据子集上完成。

### 不应混入“对比算法”的项目

- CTGAN、TVAE、TabDDPM、TabSyn是**污染数据生成器**，不是检测算法；它们用于形成多生成器测试条件。
- Adult、Insurance等是**数据集**，不是算法。
- 模型崩塌论文和推断效用论文主要提供**影响机制和评价设计**，不是样本检测器。
- Accuracy、AUROC、MAE、NMAE、Spearman等是**指标**，不是算法。

## 6. 推荐复现顺序与停止条件

1. 先以Adult构造同表、同生成器的最小闭环，跑通C2ST-XGBoost和CC/PCC/ACC/PACC。
2. 接入QuaPy，跑通EMQ、HDy、DyS、Median Sweep，输出不同污染率的MAE曲线。
3. 扩到至少3个真实表、3个生成器，增加跨生成器和跨表协议。
4. 复现D1的三条跨表基线，再实现D3 datum-wise Transformer；若官方代码发布，以官方实现替换并记录差异。
5. 在同一批污染数据上跑KNN-Shapley、Data-OOB和下游效用曲线；小规模追加TMC-Shapley/Data Banzhaf。
6. 每个算法至少满足：一个端到端运行记录、一个可重复配置、一个结果表、一个与原论文趋势的核验说明。做不到时明确标注“未跑通及原因”，不能写成已复现。
